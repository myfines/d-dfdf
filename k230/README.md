# 捏合预览 V1

CanMV IDE打开 `pinch_preview.py`，连接COM9后点击运行。所有自编代码在一个文件内，不必上传额外模块；依赖此前已在板上回读验证的 `/sdcard/k230_hand_keypoint_official.py` 及官方手检测/关键点模型。保留LCD及原有to_ide输出，不改main.py、UART或FPGA。

画面显示骨架、拇指尖至食指尖连线、OPEN百分比和进度条。只接受一只手，连续3帧有效后TRACK；没有手、多手、低置信度、几何异常立即无效，恢复后重新稳定。检测置信度门槛0.35，掌宽至少20像素。此模型没有逐关键点置信度；掌宽归一化只能减轻距离影响，手掌转侧、遮挡或误检仍会影响结果。

IDE下方串行终端约每200ms输出一行，例如：

```text
PINCH,64,TRACK,1,1,0.359,0.778,0.859,62,0,89
```

| 列 | 含义 |
|---|---|
| PINCH | 日志标记，尚不是发给FPGA的通信协议 |
| 64 | 帧序号，每帧递增，日志限速所以会跳号 |
| TRACK | 状态：TRACK / WARMUP / NO HAND / MULTI HAND / LOW CONF / BAD GEOMETRY |
| 1 | valid；0时百分比为--，不能当成0%或有效控制值 |
| 1 | 经过官方检测框过滤后的手数量 |
| 0.359 | 手检测置信度，不是关键点置信度 |
| 0.778 | 原始捏合比例：点4到8距离 / 点5到17掌宽 |
| 0.859 | 时间常数120ms的平滑比例 |
| 62 | OPEN百分比，临时将比例0.15～1.30映射为0～100并限幅 |
| 0 | 捏合闭合状态；平滑比例<0.23闭合、>0.33张开，中间保留状态 |
| 89 | 本帧获取/推理/绘图/显示耗时ms，不含随后GC，不是端到端延迟或完整FPS |

## 实物判断

1. 一只手正对镜头、张开和捏合各保持2秒：看raw/smooth与进度条是否跟随。
2. 姿态不变稍微前后移动：归一化比例应相对稳定，但不承诺完全不变。
3. 移走手：应NO HAND、valid=0、百分比--；重新放入先WARMUP再TRACK。
4. 放两只手：应MULTI HAND，无有效值。遮挡/转侧导致数值异常时先调整姿态，记录原始比例用于校准。

0.15/1.30只是初始范围，收集实际合拢/张开比例后修改PinchTracker.OPEN_MIN/MAX。百分比不是已校准音量，也不触发音符。不能靠此预览算完成第三表情维度；UART与FPGA映射均未实现。
