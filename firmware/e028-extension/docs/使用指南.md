# E028 新程序使用指南

适用固件：`instrument_e028.fs`（主版本，ESP-01S Wi-Fi）
顶板：Tang Primer 20K Dock，GW2A-18C
音频：PCM5102A，I2S，46.875 kHz
OLED：SSD1306 128×64，I2C 0x3C

## 1. 上电与解锁（必须先做）

上电后固件默认 `armed=0`，OLED、I2S、四颗 LED、ESP 都处于复位/高阻状态。必须做一次安全启动：

1. 按住 **S1 + S2** 不放；
2. 按下摇杆按钮，再松开（点一下）；
3. 松开 S1、S2；
4. 等约 **300 ms**，OLED 开始初始化；八路光键模块另需约 20 s 稳定。

只做一次。重复组合会关闭外设。

> 当前版本在解锁后 **1 秒内屏蔽面板按键动作和音符**，防止“S1+S2+摇杆”这个启动组合在松键时误触发换页/换屏/放歌。1 秒后再正常演奏。

## 2. 键位与音域

- 八路光键：当前页的 8 个音。
- 4 个页面（page 0–3）：C3–G5 共 32 个半音。
- 板载 S1–S4：同时可发高音区 4 个音；短按还会执行面板功能，所以“按键功能”在松开时触发。
- 摇杆 X：弯音 ±2 半音。
- 摇杆 Y：触发新音时的力度（同时 App 可控制亮度）。
- 摇杆点击：切换音色。

## 3. 面板操作（以实物丝印 S1–S4 为准）

| 操作 | 功能 |
|---|---|
| **S1 短按** | page +1（0→3 循环） |
| **S2 短按** | OLED 屏幕 0→4 循环 |
| **S3 短按** | 脱机曲目开始/停止 |
| **S3 长按 1 s** | 锁存（latch）开/关；配合 8 键×4 页可累积 32 个音 |
| **S4 短按** | 效果预设：关 → 合唱 → 合唱+延迟 → 全部 |
| **S4 长按 1 s** | 32 声部压力测试（32 个 gate 全开；半音簇，不是乐曲） |
| **摇杆点击** | 音色：E.Piano → Organ → Strings → Bass |

## 4. 脱机曲目与 LED

- **S3 短按**开始内置《欢乐颂》64 步（120 BPM，约 16 s 循环），再按一次停止。
- 曲目在 FPGA 内部，不需要手机/ESP。
- 四颗板载 LED（L16/L14/N14/N16）：
  - 曲目模式：LED0–LED3 对应键组 0/1、2/3、4/5、6/7；目标组亮，节拍时四灯闪。
  - 自由演奏：LED 作为声部活动条；空闲时 LED3 心跳。
- 具体是哪一个键，看 OLED 第 3 屏（八键框 + 进度条）。

## 5. OLED 五个屏幕

| 屏号 | 内容 |
|---|---|
| 0 | 波形（效果后真实音频，过零触发） |
| 1 | 16 段实时频谱（100 Hz–10 kHz） |
| 2 | 李萨如 X/Y（立体声后级信号） |
| 3 | 演奏指引：八键框高亮目标键 + 底部进度 |
| 4 | 状态：音色、效果位、声部数、延迟、曲目、屏幕号 |

S2 短按循环切换。OLED 全帧约 100 ms，频谱/波形更新是实时的，但屏幕刷新约 10 帧/秒。

## 6. 手机 App

默认 Wi-Fi 模式（ESP-01S，TCP 9000）：

- 音量 `Vxx`、音色 `Txx`、效果 `Fxx`、页 `Pxx`
- 8 键 `Kxx`、32 音掩码 `Mxxxxxxxx`
- 曲目 `Rxx`、锁存 `Hxx`、OLED 屏 `Sxx`
- 弯音 `Bxxxx`、颤音 `Xxx`、亮度 `Yxx`

BLE 版本必须烧 `instrument_e028_ble.fs`，并使用 `ble-app/FPGA-BLE.apk`；Wi-Fi 版不能直接连 BLE 模块。

## 7. 曲目为什么之前会自动播放？

旧逻辑把“安全启动组合”松开 S2 的动作误判成一次 S2 短按（S2 对应曲目开关），所以解锁后立即开始放歌。

当前修正：

1. 解锁后 1 秒内，面板短按/长按全部屏蔽；
2. S1/S2/S3/S4 的功能映射改为与面板说明一致：
   - S1 换页，S2 换屏，S3 曲目，S4 效果；
   - S3 长按锁存，S4 长按 32 声部测试；
3. 这 1 秒内也屏蔽音符，避免解锁组合本身出声。

如果仍然一解锁就放歌，说明板上跑的不是修正版，检查 `UserCode` 是否 `0xE028` 并重新烧录。

## 8. 常见问题

| 现象 | 处理 |
|---|---|
| OLED 全黑 | 先确认已做 S1+S2+摇杆解锁；未解锁时黑屏正常 |
| 解锁后 OLED 仍黑 | 查 OLED VCC=3.3 V、GND、SCL→T11、SDA→P11；不要接 5 V |
| 一启动就放歌 | 旧版 bug；烧修正版 E028，或先按 S3 停止 |
| 没有声音 | 是否已解锁；PCM5102A 的 I2S 三线；PCM 独立 USB 供电；`PA_EN=0` 是正常的（外接 PCM） |
| 光键没反应 | 八路上电后等约 20 s；检查 T9/P9；确认不是测试/编辑模式 |
| 只有 4 个音同时响 | 物理光键只有 8 个，且当前页一次 8 个；32 声部需 page/latch 或 App `M` 掩码 |
| LED 不亮 | 确认是 L16/L14/N14/N16；A13/C13 是专用脚，不能用 |
| 32 声部测试很吵 | `S4` 长按是半音簇压力测试，再长按关闭 |

## 9. 性能与边界

- 按键→合成样本仿真延迟 **1.409 ms**；I2S 串行化再加 ≤21 µs。
- 全硬件帧同步，无 CPU/中断在音频路径，抖动确定。
- 32 声部、4 音色、合唱/延迟/混响、频谱/李萨如/指引、脱机曲目均已实现。
- 尚未做示波器实测、音频主观音质、温升/长跑、BLE 真机配对。
- 4 颗 LED 只能分组指示，不能做到 8 灯一一对应；精确键位看 OLED。
