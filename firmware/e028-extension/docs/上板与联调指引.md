# 上板与联调指引（E028 候选）

## 0. 先确认

- 板卡：Tang Primer 20K Dock，GW2A-LV18PG256C8/I7（GW2A-18C）。
- 时钟：H11，27 MHz。
- 当前交付只有**仿真 + Gowin 构建**，没有下载/烧录；不要把本文件当成已验收报告。
- 上板前先核对码流哈希、UserCode（0xE028）、下载器占用和板卡供电；不要在异常发热时继续。
- 不修改 OTP、下载器固件；不整片擦除 Flash。

## 1. 接线

### 1.1 不变部分

| 功能 | 引脚 |
|---|---|
| PCM5102A | PCM_DATA P6，PCM_BCK R8，PCM_LRCK P8 |
| ADS1015 | SCL T6，SDA T7 |
| 摇杆 SW | T8 |
| 八路光键 | SCL T9，SDA P9 |
| OLED | SCL T11，SDA P11 |
| ESP/BLE | ESP_RX T12，ESP_TX R11 |
| K230 | M14 |
| UART 状态 | M11 |
| 板载键 | S1 T3，S2 T2，S3 D7，S4 T10（T10 需 SSPI 作 GPIO） |

### 1.2 变化：4 颗板载 LED

```text
led[0] L16
led[1] L14
led[2] N14
led[3] N16
```

A13/C13 是专用 READY/DONE，**不要**把 LED 约束到这两个脚；原 E027 文档的六灯接法在本封装不可用。

LED 为高电平点亮，串联电阻按板载 LED 电路；不要直接灌大电流。

### 1.3 BLE 模块

以 HM-10 / AT-09 / JDY-08 类 BLE 透明串口为例：

```text
模块 VCC -> 3.3 V（按模块规格；不要用 5 V 直接进 FPGA）
模块 GND -> Dock GND（共地）
模块 TX  -> FPGA T12 (ESP_RX)
模块 RX  -> FPGA R11 (ESP_TX)
```

HM-10 类模块注意逻辑电平；如果模块是 5 V 逻辑，必须加电平转换，不能直接接 FPGA。

## 2. 构建 BLE 版本

默认 `instrument_e027_top` 的 `LINK_MODE=0`（ESP-01S Wi-Fi AT）。BLE 版本把顶层参数改为 1：

```verilog
instrument_e027_top #(.LINK_MODE(1)) top(...);
```

或复制一个 `instrument_e028_ble_top.v` 包一层。构建脚本不变，改顶层文件后 `run all`。

BLE 模式下：

- 不实例化 `esp_at_control`，不发 AT 命令；
- `esp_command_parser` 进入 `RAW_MODE=1`，直接解析 ASCII 行；
- `ESP_TX` 高阻，不驱动模块；
- 手机 App 用 `ble-app/` 连接模块的写 characteristic。

## 3. 上电与安全启动

E027 的安全启动组合保留：

- 上电后 `armed=0`，I2S/OLED/ESP 高阻；
- 按住摇杆并配合 S1/S4 完成解锁（以 E027 实测组合为准）；
- 解锁后 `armed=1`，音频/I2S 才输出。

如果不需要安全启动，可把 `SAFE_STARTUP=0`，但量产/比赛不建议。

## 4. 建议的验收顺序

1. **只读检查**：确认板卡、芯片 ID、供电、无异常发热。
2. **SRAM 下载**：先下载 `instrument_e028.fs` 到 SRAM，不写 Flash；确认 UserCode 0xE028、DONE。
3. **心跳/按键**：LED 在自由演奏时显示声部条；按 S1 应能听到 E5。
4. **OLED**：确认 5 屏可切换，波形随按键变化，频谱有柱，指引屏高亮目标键。
5. **延迟**：示波器/逻辑分析仪测按键下降沿到 PCM_DATA 第一个有效位；目标 ≤5 ms。仿真值 1.409 ms。
6. **32 声部**：App 发 `MFFFFFFFF`，OLED 状态屏 `V:20`（32 的十六进制）；听感为半音簇，属压力测试，不是乐曲。
7. **音色/表情**：切换 4 音色；摇杆 X 弯音、App `X` 颤音、`Y` 亮度；确认不是只改显示。
8. **效果器**：`F00`/`F01`/`F03`/`F07` 对比干声、合唱、延迟、混响；确认无爆音/自激。
9. **脱机曲目**：拔掉手机/ESP，按 S3 启动；OLED 指引 + 4 灯组 + 节拍应继续。
10. **BLE**：手机装 `ble-app/dist/FPGA-BLE.apk`，扫描/连接模块，发 `V80`、`K01`、`MFFFFFFFF`；确认 FPGA 响应。
11. **温升/长跑**：至少 30 min 连续演奏/曲目，记录电流、温度、是否有丢音/死机。

## 5. 延迟测量建议

- 触发：按键或光键输出下降沿（或 App 命令发送时刻，但无线链路不计入 FPGA 延迟）。
- 观察：PCM_DATA 上第一个非零采样位，或 DAC 模拟输出。
- 记录：多次测量的 min/typ/max，计算抖动；不要只报一次。
- 光键路径含 1 ms I2C 轮询，需单独测“遮挡→出声”。

## 6. 常见问题

| 现象 | 排查 |
|---|---|
| 无声音 | `armed` 是否解锁；I2S 三根线；PCM5102A 供电；PA_EN 本工程为 0（外接 PCM） |
| OLED 不亮 | T11/P11、3.3 V、地址 0x3C；I2C 是否被光键占用 |
| LED 不亮 | 是否约束到 L16/L14/N14/N16；A13/C13 不可用 |
| BLE 连不上 | 模块波特率是否 115200；TX/RX 是否交叉；是否共地；App 是否匹配 FFE0/Nordic UUID |
| 32 声部只有几个音 | 物理只有 8 键；需 page/latch 或 App `M` 掩码 |
| 效果器自激/爆音 | 先 `F00` 旁路；检查 3.3 V 电源余量；混响反馈已限 0.5 |
| 构建退出码 1 但生成码流 | 本机 Gowin `sh.log` 缓存路径权限问题；看日志末尾是否 `Bitstream generation completed` |

## 7. 交付边界

本工程没有：

- 实物音频录音/频谱仪对比；
- BLE 真机配对日志；
- 温升/EMC/长期运行数据；
- Flash 固化。

这些必须在报告中如实标注“未测”，不能引用仿真值代替。
