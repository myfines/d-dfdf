## 2. 源码

- `src/`：27 个当前 RTL（含 `instrument_e027_top.v`、`instrument_e028_ble_top.v`、`synth32.v`、`fx_engine.v`、`spectrum16.v`、`oled_ui.v` 等）。
- `constraints/instrument_e027_ext.cst`：E027 Dock 引脚；`led[3:0]` = L16/L14/N14/N16。
- `constraints/instrument.sdc`：27 MHz。
- `legacy/`：旧 E027 4 声部/测试库 RTL，不参与综合。

## 6. Android BLE

- `ble-app/src/`：`com.fpga.instrument.ble` 源码（MainActivity / BleController / PianoView / Protocol）。
- `ble-app/dist/FPGA-BLE.apk`：49,636 bytes，SHA256 `9FE8CCDE88C8A8FBE772107E47938438F1C2165507C30C73C243F9D70983E244`。
- `ble-app/build.ps1`：离线 JDK17 + Android SDK 34 构建；`apksigner verify` v2/v3 通过。
- `ble-app/README.md`：配对、UUID、命令、排错。
- App 是 **BLE-GATT**；只支持经典 SPP 的 HC-05 不能直连，应使用 HM-10/AT-09/JDY-08 或 Nordic UART 模块。
- 未做 Android 真机 BLE 配对。
