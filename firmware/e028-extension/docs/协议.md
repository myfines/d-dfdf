# E028 串口协议

## 1. 物理层

| 模式 | `LINK_MODE` | 模块 | 波特率 | 帧格式 |
|---|---:|---|---:|---|
| Wi-Fi（默认） | 0 | ESP-01S，AT 固件，TCP 9000 | 115200 | 8N1 |
| BLE-UART | 1 | HM-10 / AT-09 / JDY-08 等 BLE 透明串口（GATT） | 115200 | 8N1 |

引脚不变：

```text
FPGA ESP_RX = T12  <- 模块 TX
FPGA ESP_TX = R11  -> 模块 RX
GND 共地；模块 3.3 V 供电（按模块规格）
```

BLE 模式不使用 AT 命令，FPGA 把串口收到的每个字节当作命令负载；Wi-Fi 模式仍使用 `+IPD,<client>,<len>:<payload>` 封装。

## 2. 命令格式

每条命令是 ASCII 行，以 `\n` 结束；`\r` 被忽略。十六进制数字大小写均可。

| 命令 | 参数 | 说明 |
|---|---|---|
| `Vxx` | 00..FF | 总表情音量；255 最大 |
| `Txx` | 00..03 | 0 E.Piano，1 Organ，2 Strings，3 Bass |
| `Kxx` | 00..FF | 8 位键掩码，bit j = 当前页第 j 个光键/手机键 |
| `Pxx` | 00..03 | 页；每页 8 个音，共 C3–G5 |
| `Fxx` | 00..07 | bit0 合唱，bit1 延迟，bit2 混响 |
| `Mxxxxxxxx` | 8 hex | 32 位绝对音掩码，bit n = 音符 48+n（C3..G5） |
| `Bxxxx` | 0000..3FFF | 弯音，0x2000 为中心；14 位有符号偏移 |
| `Xxx` | 00..FF | 颤音深度 |
| `Yxx` | 00..FF | 亮度（低通截止） |
| `Sxx` | 00..04 | OLED 屏：0 波形 1 频谱 2 李萨如 3 指引 4 状态 |
| `Rxx` | 00/01 | 脱机曲目启停 |
| `Hxx` | 00/01 | 锁存开/关 |
| `Dxx` | 00/01 | 32 声部压力测试（全 gate） |
| `Q00` | 00 | 保活/续租 |
| `L00` | 00 | 释放手机键、清覆盖、租期归零 |

## 3. 示例

```text
V80\n          音量 128
T02\n          弦乐
P01\n          第 1 页（C4..G4）
K81\n          只按第 0、7 个键
F07\n          合唱+延迟+混响全开
B2400\n        向上约 1 个半音（0x2400-0x2000=0x400）
MFFFFFFFF\n    32 个音全开（压力测试）
M00000000\n    释放全部 32 音
R01\n          开始脱机曲目
H01\n          锁存开
L00\n          手机释放
```

## 4. 租期与优先级

- 任意有效命令刷新 5 s 租期（`LEASE_TICKS=135,000,000` @27 MHz）。
- 租期到期：清手机键、App 覆盖、曲目/锁存/压力测试，音量回 255。
- App 的 `M` 掩码与本地键是“或”关系；本地键始终可弹，不会被 App 完全锁死。
- `L00` 立即释放。

## 5. Wi-Fi 封装

ESP-01S 模式下，命令放在 TCP 数据里，FPGA 先解析：

```text
+IPD,0,4:V80\n
```

`esp_command_parser.v` 支持 0..4 号 client、长度 1..4096、分包/粘包；行缓冲 12 字节。`M` 的 8 位十六进制 + `\n` 共 10 字节，在 12 字节内。

## 6. Android BLE App

`ble-app/` 提供 `com.fpga.instrument.ble`：

- 扫描并连接 BLE-UART 模块；
- 自动匹配 HM-10（`FFE0/FFE1`）或 Nordic UART（`6E400001.../6E400002...`）；
- 8 键、音量、音色、效果、页、曲目、锁存、32 声部压力测试；
- 写入上述 ASCII 行。

注意：BLE 模块的写 characteristic 通常一次最多 20 字节（未协商 MTU）；本协议单条最长 12 字节，安全。
