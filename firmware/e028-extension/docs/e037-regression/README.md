# E037 功能补齐与验收边界（2026-10-29）

## 本轮实现
- 保留32独立相位/频率/ADSR声部、实时变调、多音色、FPGA效果、光键/摇杆/K230、OLED/LED与安全启用逻辑。
- 32位置自定义键位：光键与手机分页键共用表，校验/越界拒绝、默认恢复，掉网后本地表保留，重新上电或关闭外设后恢复默认。
- 可下载64事件曲谱：每事件音符0..31或休止、时长1..255个469音频帧（约10ms）单位。写入时须停止曲谱，校验且连续条目完整后提交；未完整提交不得播放下载内容。曲谱是音符事件，不是预录PCM。下载后不依赖网络，用本地S3短按启停；重启后需重新下载。
- 数字录音：实时后效果PCM，8点箱式平均后降采样，4096个signed8单声道点，实际采样率46875/8Hz，约699ms。128块，每块32字节、有校验，可回传并导出WAV（整数标称采样率5859Hz）。低带宽监听/短录音，不是连续高保真推流；箱式滤波抑制带外有限，不能冒称高质量重采样。
- 96字节A数据包承载实际录音、曲谱完整提交状态、当前分块对应的映射音符及ADSR配置。屏幕波形G/S数据绝不当作录音。
- 网页WebMCP增加曲谱下载/播放、录音启动/选块/导出。中继分批发送，队列有上限；紧急释放清空旧上传及远程按键，防止重连复活旧音符。
- 原生Android伴侣0.5新增公网入口，可下载曲谱并等实际提交状态、配置映射、收齐128块后保存WAV。保持原手机网络，令牌不打包、不保存。与用户偏好的旧APK分开，旧APK原件不修改。新APK编译/签名/编码测试通过，尚未在实体手机安装运行。
- Dock LED为低电平亮，输出极性修正；未启用音频时独立心跳，不再依赖已复位的音频帧。

## 测试证据
28项完整RTL回归，另加未启用心跳测试通过；8项中继、2项录音组装、WebMCP及Android既有/新增编码与socket测试通过。完整E037时序27MHz约束，Fmax27.208MHz，setup/hold TNS0，余量仍小。

E03D隔离自测使用生产模块的诊断派生版本、内部自动控制指令及USB-B返回，外设总线高阻，不访问Wi-Fi：实际接收414个有效A包、零畸形A包、128块全部齐全；映射位置0读回31；下载曲谱读回3事件完整；ADSR读回9CDA0；导出WAV有非零实时PCM。细节与SHA见board-integration-test.json；诊断WAV可追溯，不作为乐器播放输入。

首次自测把录音放进启用后1秒静音保护期，得到全零；调整自测时间后通过，正式保护未移除。后续提高诊断音量，避免signed8仅有极少量化级。普通G包与空行不计为畸形录音包。

## 严格验收仍未完成的项目
这些限制不因Flash写入而消失：公网中继当前未运行，真实ESP→公网→APK端到端未验证；Android实体安装未验证；实体输入到模拟输出的5ms/10ms延迟和抖动未同步测量；真实OLED帧率/现场视觉未摄录验收；32音可闻独立频点仍需校准音频链路收口。Wi-Fi不称已验证蓝牙，FAQ副本也未明确确认二者等价。

历史录音尾音/保持电平偏差按用户要求保留待查。先前板上数字包络正常，不因此认定整个模拟链路正常。历史突发温升根因没有确认解决。

## Flash
本轮用户授权写入，并完成断电重连。官方operation37 GAO-Bridge、2.5MHz、地址0，返回Program and Verify flash successfully，100%，28.46秒。紧接着用户码读回0000而非E037，已请求完整断电启动；随后用户完成完全断电重连，未下载SRAM，只读op73 E037、op74 6020且exit0，Flash自启动通过。具体以flash-result.json及冷启动日志为准。
