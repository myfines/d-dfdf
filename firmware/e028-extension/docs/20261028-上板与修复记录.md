## 2. OLED 不亮的排查

第一次冷启动后 OLED 全黑、四灯亮。原因不是 OLED 坏，而是：

- E028 保留 E027 的安全启动；
- `armed=0` 时 `io_reset_n=0`，OLED/I2S/LED 都处于复位/高阻；
- 必须做 **S1+S2 + 点摇杆** 的解锁组合；
- 解锁后约 300 ms OLED 才开始初始化。

用 E027 临时 SRAM 启动做隔离测试，按解锁组合后 OLED 正常，证明 OLED 与接线正常。之后恢复 E028。

## 3. 解锁自动放歌

根因：

- 启动组合要按住 S1+S2，再松手；
- 旧 `panel_ctrl` 把 S2 的松键当成一次短按，而 S2 当时被映射为曲目开关；
- 所以一解锁就 `song_enable=1`，开始播放《欢乐颂》。

修复：

- `instrument_core` 在解锁后产生 1 s `panel_inhibit`；
- 1 s 内 `panel_ctrl` 不响应短按/长按，`performance_gate` 也置 0，避免解锁组合本身出声；
- 重新按实物丝印修正 S1–S4 映射：
  - S1 换页、S2 换屏、S3 曲目、S4 效果；
  - S3 长按锁存、S4 长按 32 声部测试。

注意：最初计数器写成 46875 个时钟（1.7 ms），不足以覆盖松键；已改为 27,000,000 个时钟（1 s）。

## 4. 声音拖尾与爆鸣

### 4.1 拖尾过长

旧包络 Release 每个音频帧只减 1 LSB：

```text
65535 × 2 / 46875 ≈ 2.8 s  (E.Piano)
65535 × 3 / 46875 ≈ 4.2 s  (Strings)
```

改为每帧减 4–8：

| 音色 | Release |
|---|---:|
| E.Piano | ~175 ms |
| Organ | ~233 ms |
| Strings | ~350 ms |
| Bass | ~175 ms |

### 4.2 爆鸣/怪异

同时修正：

- 去掉按声部数切换的 `mix_shift`，避免 1→2/2→4/4→8 声部时增益突然减半造成台阶/爆音；
- 每个音触发时写入独立相位种子，避免 32 个声部同相叠加产生爆鸣；
- 默认效果器改为关闭（干声），先排除合唱/延迟/混响的调制和拖尾；
- 1 s 解锁屏蔽期间同时静音，避免启动组合出声。
