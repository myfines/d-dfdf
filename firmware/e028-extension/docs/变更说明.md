# 相对 E027 的变更

基线：`firmware-e027/package`（E027 干净构建包，已综合成功）。
GitHub `main` 最新提交为 E026；E027 是本地/候选包。2026-10-27 修改过的 `Gowin-E027-Project` 不采用，因为其中：

- `optical_keys_reader.v`：`timescale 1ns/1pso`、`reg [2:0] sate`（应为 `state`），无法编译；
- `io_arm_control.v`：复位分支里 `armed=0` 阻塞赋值、`previous_sw` 位置异常，风格/可综合性风险。

## 新增 RTL

| 文件 | 作用 |
|---|---|
| `src/synth32.v` | 32 声部引擎（独立相位/包络/力度/音色） |
| `src/fx_engine.v` | 合唱/延迟/FDN 混响，立体声 |
| `src/spectrum16.v` | 16 段实时 biquad 频谱 |
| `src/note_router.v` | 32 gate 映射、latch、App 掩码、按钮去抖 |
| `src/song_player.v` | 脱机《欢乐颂》64 步 + 低音 |
| `src/led_guide.v` | 4 颗板载 LED 曲目/声部指示 |
| `src/panel_ctrl.v` | 新面板操作（page/screen/song/latch/FX/timbre） |
| `src/esp_command_parser.v` | 可变长度 ASCII 命令 + `+IPD`/RAW 双模式 |
| `src/oled_ui.v` | 5 屏 OLED（波形/频谱/李萨如/指引/状态） |
| `src/instrument_core.v` | 新数据流中心，替代 `instrument_io.v` |
| `src/instrument_e027_top.v` | 新顶层，`led[3:0]` 替代 `LED_ALIVE/LED_ADC` |

- `ads1015_reader.v`、`i2c_register_bus.v`、`optical_keys_reader.v`、`io_arm_control.v`；
- `i2s_tx16.v`、`uart8n1.v`、`uart_status.v`、`esp_at_control.v`、`esp_volume_parser.v`、`wifi_telemetry.v`；
- `gesture_uart_rx.v`、`gesture_packet_rx.v`、`gesture_expression.v`；
- `oled_i2c_stream.v`。

## 移除/存档

`legacy/`：`instrument_io.v`、`voice_engine.v`、`spectrum_bank.v`、`short_delay.v`、`mode_router.v`、`adsr_envelope.v`、`adsr_runtime.v`、`instrument_panel.v`、`oled_scope.v`、`optical_key_allocator.v`、`remote_audio_gain.v`、旧顶层/诊断顶层。
`sim/legacy/`：旧 E027 testbench。

这些文件不再参与 `tools/build_e028.tcl`。

## 引脚变化

- 音频/ADC/光键/OLED/ESP/K230 不变。
- `led[0..3]` = L16/L14/N14/N16。
- A13/C13 是专用 READY/DONE，不用。
- 若保留 E027 的 `LED_ALIVE/LED_ADC` 端口名，需在约束中改成 `led[3:2]`；本工程直接用 `led[3:0]`。

## 行为变化

- 4 声部分配器被 32 声部固定槽位取代；
- 测试模式从“32 个固定频率正弦库”改为“32 gate 全开压力测试”；
- 硬件短延迟（43.7 ms 回声）改为完整效果链（合唱/延迟/混响）；
- OLED 页面从“键框/状态/波形”扩展为 5 屏；
- 面板短按/长按含义见 README；
- App 协议新增 `M/B/X/Y/F/S/R/H/D`，旧 `V/T/E/K/P/Q/L` 保留。
