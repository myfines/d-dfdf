# E030 ESP热点网页控制

网页不依赖已关机的华为服务器。参考本机D:/root/hwi-server/HOMEPAGE-STATUS.md的轻量本地页面思路，未复制其登录、SSH或公网凭据。

## 使用

1. 保持现有接线；PCM USB供电，PCM 3.3V排针不接；Dock正常供电。
2. 安全启用仍需按住S1+S2，按下并松开摇杆，再松开两键，仅一次。
3. 连接Wi-Fi `FPGA-Instrument`，密码 `fpga-demo-2026`。无互联网是正常现象。
4. 浏览器打开 **http://192.168.4.1:9000/**。端口9000不能省略。
5. 网页键盘按住发声、松开停止；支持多指和弦、四音色、音量、亮度、颤音、弯音、效果、OLED切页、曲目和32声部示范。声音仍从PCM输出，不通过手机扬声器。
6. STOP ALL停止网页产生的音符、示范和曲目，不抑制仍被遮挡的实体光键。切出网页会发送同样停音，链路失联后沿用FPGA约5秒控制租约释放。

## 实现与兼容

ESP-01S保留AT固件；HTML/gzip响应存于FPGA ROM，由FPGA经AT+CIPSEND发送。网页实际随FPGA码流固化，不需要刷ESP、Linux服务器、CDN或新接线。压缩响应小于2048字节，生成工具会检查限制。参考[乐鑫ESP8266 AT说明](https://www.espressif.com/sites/default/files/documentation/4a-esp8266_at_instruction_set_en.pdf)。

HTTP GET /返回网页，/c/加现有十六进制指令提交控制，/status返回当前遥测快照；每次响应后关闭TCP连接。原APK原始TCP指令入口不改；建议一次只连接一个控制端，网页和APK不要同时争用控制。热点密码是原演示配置，网页只用于该本地热点，不映射到公网。

HTTP请求与APK命令分开解析，非法十六进制返回400；TCP拆包保持请求行。输入行限制64字节。网页串行发送请求，STOP会取消队列里尚未发送的旧音符；轮询最多排队一次。
