# E029 质量改进候选（2026-10-28）

基线：E028 f54442c，Flash 写入记录 52581b9。本候选另开 e029-quality 分支；保留 E028 回退。

## 修复与重写

- OLED 重新组织为固定标题/音色、图形、底部操作提示；频谱、波形、立体声 XY、八键指引、状态保留五页。
- 所有显示数据在完整 I2C 帧之间快照，波形抓取完成后重新启动，避免旧代码只采一次而永久冻结。频谱底部向上增长，曲目停止时不保留虚假目标键。
- XY 采用当前左右声道快照散点，不再使用清除一轮需数秒的历史残影缓存。
- brightness=248..255 时，原8位 alpha 加法溢出；改为饱和系数，避免亮度推到顶反而变闷或无声。
- LFO 补齐完整正负64点周期，避免颤音不对称、音高偏移。
- 效果菜单修复 0→0 卡死，循环改为0→1→3→7→0；长按不再被测试误当短按。
- 四种音色采用不同谐波族和包络：电钢琴1/2/3、风琴1/2/4、弦乐1/3/5、贝斯1/2；取消未带限的锯齿/方波叠加。
- 电钢琴减少持续电平、加快自然衰减；弦乐慢起音；干声仍为默认。

## 自动录音探针

工具 tools/audio_probe.py 默认只打印测试计划。--list-devices 仅枚举输入。显式 --run --device N 后，通过现有TCP9000发送低音量测试命令，保存真实PC输入WAV和JSON；终于退出时发送全部停音。测量峰值、RMS、直流、削波比例和主谱峰。主谱峰不总是基频，主机命令时间不证明硬件延迟，麦克风AGC影响幅度对比。

用户已确认PCM输出接入电脑，正常E029已下载SRAM，另以E02A临时探针完成DAC实录。历史异常温升根因未测明，不因此候选编译通过而宣称解决。

## E029 按键标识更正

依据工程约束与已有接线记录：S0/T10、S1/T3、S2/T2、S3/D7。原 E028 把 btn[0] 写成 S4 是命名错误；RCFG 是独立硬件重配置键，不是功能键。本轮只更正命名，不改变已使用的引脚和安全启用组合。

- S0 短按：效果0/1/3/7循环；长按：32声部测试。
- S1 短按：音域页；S2 短按：显示页。
- S3 短按：曲目；长按：锁存。
- 摇杆点击：音色；启用仍为S1+S2配合摇杆，仅操作一次。

## 自审边界

本轮不修改电压标准、引脚约束、ESP握手或Flash；保留完整E028回退。数值边界、状态隔离、显示帧一致性和工具退出停音均有测试。原四音色测试只比较能量，新增归一化频谱比较，避免把音量大当音色更不同。32声部测试增加逐路包络非零与相邻相位状态独立检查。OLED声部字段来自gate计数，不是释放尾音数量；不据此单独认定32个实际可闻独立峰。
