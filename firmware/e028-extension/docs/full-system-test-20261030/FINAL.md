## 真实修复与纠正

1. App0.12录音途中断开，重连30秒无普通状态。0.13每次新TCP先发C00000000退出遗留回传模式；单测RED→GREEN，真手机直接断开和HOME后台恢复约3.45/3.57秒。未改FPGA生产逻辑。
2. 音频诊断刺激在多声部释放时错误恢复较大音量上限，初次全窗口发现264近满幅样本。修正探针释放上限并增加全窗口检查；重录30个完整2秒窗口近满幅0，24项检查通过。仅证明该衰减4倍配置，不能推广任意正式最大增益；PC麦克风直录正式增益会过载。
3. 已撤回摇杆失效推断；完整专项证据证明两轴和弯音有效，无需修改ADC。
4. ESP热点曾消失；最小AT及原初始化器探针后恢复并被手机真实连接。最初故障未稳定复现，不能宣称永久根治。未改ESP固件，电脑从未加入ESP热点。
