## 真实输入观测结果与失败项

E051采集180秒共6058条周期快照，实际启用发生在约31秒，约51秒光键初始化完成。623条已启用E0记录中ADC有效、OLED在线，540条光键有效记录；采样中ADC/光键错误均为0。手势active曾为真，捏合0..1000、高度0..731、最终expression14..255、亮度37..188。注意各记录类型轮换，范围不代表满量程校准。
