## 方法与证据边界

- 开始通过 WebMCP 控制，完成四音、独立释放、弯音和32音。浏览器批量调用超时后，其余通过同一中转服务的鉴权 HTTP API 完成；没有连接 ESP 热点，没有把 API 调用冒称 WebMCP 调用。
- 真实信号链：FPGA→I2S→PCM5102A→电脑 Realtek 麦克风输入，48 kHz 单声道录音；这不是用手机/电脑软件合成冒充 FPGA 发声。ADC 的48k录音率不能用作DAC采样率证据。
- 麦克风接口可能存在 AGC、压缩、限幅和偏置，测量 dBFS 不是 DAC 电压、声压或音质评分；没有标定 THD/SNR。单声道不能验证立体声分离。
- 本地保留27段原始 WAV，位置 E:/gaoyun/private/esp-web/acceptance-20261028；不上传麦克风原始录音。evidence-index.json 保存名称、SHA256、文件尺寸，公开 JSON 为测量结果和板子遥测，不含凭据。
- 用户本轮确认不烫且未操作光键、摇杆和K230。因此本轮不把远程注入替代物理动作采集验收，也不把短时正常当温升验收。

## 失败与待修复项

1. 弯音映射线性近似使上下音程不对称。实际中心C4约261.5Hz，边界约296/227.5Hz。下一版应使用符合半音比率的查表/分段近似，回归中心及两端音分误差。
2. 延迟反馈异常：fx-delay录音clip_fraction=0.0010625；V16复测仍0.00019444，末秒约−17.84dBFS。候选原因是fx_engine.v的delay_next中拼接量没有显式signed，可能导致逻辑右移。最小探针源码已保存，但本机Icarus执行失败（Unable to open input file、E: not recognized、后续退出1无输出），**尚未用该探针确认根因**，不把候选原因写成已证实。
3. AGC/输入增益可能影响响度与尾音量化；但不能因此抹掉实测削波。需要数字侧脉冲/负半周/零输入收敛仿真和修正版实录交叉定位。
4. 本地≤10/5ms、物理交互、OLED/LED、真正脱机和手机扩展仍需对应证据。本轮没有全部测试完成、整机满分或长期热稳定结论。
