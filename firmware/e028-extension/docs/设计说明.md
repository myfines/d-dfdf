## 2. 32 声部引擎（`synth32.v`）

### 2.1 声部映射

32 个槽位固定对应半音 C3..G5（MIDI 48..79）。`gate_mask[n]` 直接控制第 n 个槽位，因此：

- 8 个光键 × 4 页 = 32 个绝对音；
- App `Mxxxxxxxx` 可直接给出 32 位掩码；
- 锁存模式把每次按键变成持续音，可累积 32 个音；
- 32 声部压力测试把 32 个 gate 全开。

每个槽位有独立状态：

```verilog
phase[32]        32 位相位累加器
env_level[16]    16 位包络电平
env_counter[16]  16 位衰减/释放计数器
env_state[3]     IDLE/ATTACK/DECAY/SUSTAIN/RELEASE
env_velocity[8]  该音触发时的力度
env_timbre[2]    该音触发时的包络音色
```

渲染时按 32 个时隙串行复用一套正弦 ROM/乘法器，但**状态不共享**。每声部 9 个时钟：

```text
LOAD → ENV → LOOK(h1) → HARM(h1) → LOOK(h2) → HARM(h2)
     → LOOK(h3) → HARM(h3) → COMB
```

32×9 = 288 时钟，小于一帧 576 时钟（27 MHz / 46.875 kHz），因此每帧都能完整刷新 32 个声部。

### 2.2 频率与弯音/颤音

- 32 项 32 位频率表，`inc = f/46875 × 2^32`；
- 弯音：摇杆 X 中心 825，±2 半音，`ratio = 65536 + bend×8600/8192`；
- 颤音：5 Hz 正弦 LFO（64 项），深度 0..255，叠加到 `ratio`；
- 每个声部 `phase += (note_inc × ratio) >> 16`。

### 2.3 包络与音色

四种音色的 ADSR 参数在 `attack_step/decay_ticks/sustain_level/release_ticks` 中：

| 音色 | 谐波 | 包络特征 |
|---|---|---|
| E.Piano | h1+h2+h3，h2 随力度增强 | 快起音、中速衰减到较低延音 |
| Organ | h1+h2+h3，接近等幅 | 极快起音、全延音 |
| Strings | h1+h2+h3 + 失谐锯齿对 | 慢起音、高延音 |
| Bass | h1 + 方波 | 快起音、较快衰减 |

`harmonic_weight` 控制每帧三次正弦查表的权重；Strings 额外加入两路相差约 1/32 周期的锯齿，Bass 加入方波。

### 2.4 动态归一化

32 个声部相加可能溢出。原实现固定 `>>5`，单音会被压到 1/32。现在按“正在发声的声部数”选择 0..5 位移：

```text
1 声部 >>0，2–3 >>1，4–7 >>2，8–15 >>3，16–31 >>4，32 >>5
```

单音与 32 音的感知音量接近，最后仍有 16 位饱和。

## 3. 表情维度

| 维度 | 来源 | 作用点 |
|---|---|---|
| 力度 | 触发时摇杆 Y（或 App/默认） | 每声部 `env_velocity`，进入增益 |
| 弯音 | 摇杆 X 或 App `B` | 全局相位增量比 |
| 颤音 | App `X` 或 K230 捏合 | 5 Hz LFO 叠加到相位增量比 |
| 亮度 | App `Y` 或 K230 高度 | 后级一阶低通截止 |
| 震音 | 由颤音深度派生 | 后级幅度调制 |
| 总表情 | App `V` 或 K230 增益 | 最终输出乘法 |

低通：

```verilog
lp += (mix - lp) * alpha >> 8
alpha = brightness + 8
```

## 4. 效果器（`fx_engine.v`）

单声道输入，立体声输出。每帧 4 个状态：IDLE→READ→CALC→WRITE。

| 效果 | 存储 | 延迟 | 说明 |
|---|---|---:|---|
| Chorus | 1024×16 | 320–447 样本（6.8–9.5 ms） | 0.5 Hz 三角 LFO 调制读地址 |
| Delay | 2048×16 | 2047 样本（43.7 ms） | 反馈 0.375，左右不同抽头 |
| Reverb | 2×2048×16 + 256×16 + 512×16 | 31.9/40.0 ms + 全通 4.8/9.4 ms | 2 线 FDN（交叉反馈 0.5）+ 2 级 Schroeder 全通（g=0.5） |

所有延迟线用同步 BSRAM，读地址和写地址分开计算；效果关闭时旁路，不访问 RAM。混音：

```text
L = dry/2 + chorus/8 + delay/8 + reverb/8
R = dry/2 + chorus/8 + delay/4 + reverb/8
```

## 5. 实时频谱（`spectrum16.v`）

16 个固定 biquad 带通，中心频率按对数分布 100 Hz–10 kHz，Q=2，系数 Q14。每帧对 16 个 band 依次做 4 次乘加（b1=0），共 64 次乘法；输出取绝对值、平滑、8 位。滤波器状态 `x1/x2/y1/y2` 每 band 独立。

频谱读的是效果后立体声左声道（`fx_l`），所以显示的是实际听到的信号。

## 6. OLED（`oled_ui.v`）

SSD1306 128×64，I2C 0x3C，100 kHz。命令初始化 25 字节，随后每次 1024 字节显存流。5 种屏幕：

0. 波形：过零触发，128 点，线段连接；
1. 频谱：16 band × 8 列，柱高 `band>>2`；
2. 李萨如：64×32 位图，X/Y 来自 `sample_l/sample_r`，每 16 帧打点，5.6 s 衰减；
3. 指引：8 个 16 px 键框，目标键整列点亮；底部进度条；
4. 状态：音色、效果、声部数、延迟、曲目、屏幕号。

I2C 全帧约 100 ms；音频/合成不等待显示。

## 7. 脱机曲目与 LED

`song_player.v` 内置《欢乐颂》64 个八分音符（120 BPM，16 s 循环），每步一个旋律音 + C3/G3 低音；每步先拉低 1 帧再置新 gate，保证重复音重新触发。

`led_guide.v` 用 4 颗板载 LED：

- 曲目模式：LED0..3 对应键组 0/1、2/3、4/5、6/7；目标组亮，节拍时四灯闪；
- 自由演奏：LED 作为声部数条，LED3 心跳。

A13/C13 是专用 READY/DONE，不能做普通 LED，所以不是 6 灯。

## 8. 串口与 App

`esp_command_parser.v` 支持两种传输：

- `RAW_MODE=0`：解析 `+IPD,<client>,<len>:` 后的 ASCII 行（Wi-Fi AT）；
- `RAW_MODE=1`：每个字节直接进入行缓冲（BLE 透明）。

`instrument_core` 的命令寄存器 + 5 s 租期决定 App 覆盖；本地键始终有效。

## 9. 延迟预算

| 环节 | 时间 |
|---|---:|
| 按键同步 + 64 帧去抖 | 1.365 ms |
| 合成一帧 | 21.3 µs |
| I2S 一帧 | 21.3 µs |
| 串行位 | ≤21.3 µs |
| **合计（按键路径）** | **≈1.43 ms** |
| 光键 I2C 轮询（另计） | ≤1 ms |

全路径无 CPU、无中断、无动态调度；帧率由 27 MHz/576 固定分频，因此抖动是确定性的。`tb_core` 实测 1.409 ms。
