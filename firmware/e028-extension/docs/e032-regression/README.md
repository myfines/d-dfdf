# E032 第一阶段整改（2026-10-28）

基线E031/85729e2。此次只修数字反馈/初始化与弯音，不改变引脚、ESP网络配置、K230协议、采样率或原E031 Flash。

## 阅读与采用

- tiny-synth https://github.com/gundy/tiny-synth ：声部相位与ADSR参数分离、参数化包络。后续ADSR接口参考，未复制源码。
- Freeverb https://gist.github.com/rxi/e5488c6660154329ddfc4a7a7d2997f8 ：明确缓存初始化、反馈路径与干湿控制。此次采用初始化和受控反馈的设计原则，不移植浮点C或复制算法代码。
- 本工程新增指数表为数学公式生成的原创常数；不包含录音样本。

## 已复现与修改

1. 原delay_next表达式拼接值为unsigned，负反馈−8000经3/8得到+29768而非−3000。最小复现与新tb_audio_fix同时确认失败；修复为显式signed。
2. 原仿真测试替硬件预清RAM；实际RTL未做缓存初始化。新增同步写零扫描，2048时钟约75.9us；扫描期间只旁路干声，湿声不读未初始化RAM，模式变化重新清缓存。保持同步数组访问，等待综合确认RAM推断。
3. 原弯音线性近似全范围误差约43.5358音分。改为Q16指数查表+插值，中心比率1，上边界单独精确处理；穷举16384个输入对比指数参考最大约0.044854音分。颤音仍沿用原加性调制，尚未完成音程域统一，不声称该项已修好。

## 测试

红灯证据audio-fix-red.log；绿灯tb_audio_fix.log、tb_fx_stability.log。后者不从测试台写RAM，测试上电静音、负脉冲符号、50000帧尾音衰减和重新开启无旧尾音。

12项通过：tb_audio_fix、tb_fx_stability、tb_quality、tb_panel_quality、tb_synth32、tb_features、tb_fx、tb_spectrum、tb_oled_ui、tb_song_led、tb_command、tb_core。旧测试仅作为回归，不能替代新增负半周/初始化测试。
