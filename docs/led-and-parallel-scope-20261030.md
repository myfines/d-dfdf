# LED与32声部的赛题边界

依据：官网选题二摘录 `competition-topic2-source-20261029.md`，以及用户提供FAQ第77条。本文澄清实现，不新增验收门槛。

## LED不能直接取消

拓展4明确要求“实现脱机演奏 LED 曲目指引功能”。OLED可承担更精确的琴键/节奏显示，但没有获得官方确认前，不能声称它替代LED后仍完整覆盖这项要求。基础三项没有独立LED要求；取消LED主要影响拓展项。

现有正式约束为4个板载GPIO灯：L16、L14、N14、N16。`led_guide.v`按八键两两分组指示，并提供节拍闪烁；OLED曲目指引页显示八个位置。引脚有效低，顶层做反相。A13/C13并非额外两个用户GPIO。代码路径存在，不等于实物板载灯已正常工作；用户提出不支持/不亮时，不能只凭代码判定硬件支持。此次已纠正顶层残留的“六灯”注释，功能逻辑未改。

## 八路巡线模块的灯

现有接口为地址0x12、寄存器0x30的传感状态读取，FPGA没有独立控制八个指示灯的接口实现。已有资料也没有给出独立LED写寄存器。传感器自带的检测状态指示，即使随遮挡亮灭，也不能冒充按曲谱主动亮起的提示灯。

因此，不能仅修改当前I2C读取代码就承诺能控制八个灯，也不应试写猜测寄存器或把X1–X8检测输出改接成FPGA输出。若该版本厂家确有灯控命令，可按正式协议扩展；若没有，则需要模块固件/电路改造或另加可控LED。现阶段保留板载四灯输出和OLED精确提示，不未经授权改模块固件/接线。没有要求一定八灯一一对应八键。

## 大规模并行合成

拓展1的三条路线是“≥32复音”或“≥32加法分量”或“多条并行物理建模”，并非全部实现。当前采用32复音路线：32份独立相位、包络、力度、音色/ADSR状态；每个音符有对应频率，运算单元和正弦ROM采用TDM共享。不是32套物理并排的完整合成算术电路。

FAQ77原问使用4-lane TDM、每采样周期轮询32个独立phase/FCW/ADSR voice算4还是32，回复“算32个”。其统计口径支持独立声部状态，不能把例子中的4-lane写成当前实现。当前源码是共享计算路径，声部之间的独立状态与最终混音构成32复音能力；为追求字面“并行”临时复制32套运算电路不是赛题的必要条件。

当前设计时钟27MHz、每帧576拍、设计采样率46,875Hz；源码调度预算为每帧内完成32声部。设计吞吐量32×46,875=1,500,000声部采样/秒。这是设计值，实际可闻声部数和LRCK率由用户按赛题现场验证。不得把谐波峰叠算成独立voice，也不得把设计值写成仪器实测成绩。

建议交付表述：“32独立状态声部的HDL实时TDM合成引擎；四灯分组曲目指引与OLED八键精确提示。”当板载灯实物不可用时，LED拓展缺口仍须如实保留，OLED不自动消除它。
