# 八光键候选程序（未部署）

2026-10-12，离线实现并验证。核心板快速发热原因仍未知，不访问板卡、不解除hardware-hold，不把仿真/编译通过当作热安全。

## 输入与演奏

- 独立I2C：SCL=T9、SDA=P9，保留ADS的T6/T7。模块地址0x12，状态寄存器0x30。
- 每次FPGA复位后等待20秒，再写0x30指针、STOP、直接读一字节；最后一个字节NACK。符合提供的MSPM0示例交互顺序，新增总线直接读分支不改变ADS带指针的重复START路径。
- 原始bit7为X1、bit0为X8，软件重排成内部bit0对应X1。每通道连续两个读样一致才改变状态，不因某一路抖动阻塞其他路。
- 读取NACK/超时立即把8键置为松开、失效后重试。声部正常释放，不强称无尾音。
- 8个光键控制最多4复音，已有按住的音符优先保留，空出的声部按输入序号分配；其他保持中的键等待空位，不突然抢占当前声部。
- 模块稳定在线后，板载S0–S3仅用于既有摇杆组合/包络编辑，不再直接演奏。模块等待/断连时自动回退原板载四键演奏。
- 使用原4个相位/ADSR声部，缓存光键频率、分配时重触发包络。复用原摇杆弯音、音色、低八度、延迟和32测试模式；编辑/测试模式释放光键分配。

## 音符分组

按住板载S0并短按摇杆切换分组。光键X1到X8：

| 分组 | X1–X8 |
|---|---|
| 0 默认 | C5 D5 E5 F5 G5 A5 B5 C6 |
| 1 | C5 C#5 D5 D#5 E5 F5 F#5 G5 |
| 2 | G5 G#5 A5 A#5 B5 C6 C#6 D6 |

低八度对整组生效。原板载回退模式的C/D/E/G等三组音符仍不变。

## 触发极性与校准

默认ACTIVE_LOW=1：厂家黑线0作为触发、白面1作为松开。若实际使用黑色静止背景、白色/手指反射作为触发，应在instrument_optical_top参数中选ACTIVE_LOW=0重新构建，两种极性都已数字测试；不能猜手遮住必为0。模块必须先在实际高度独立完成黑/白校准，通信ACK成功不代表校准成功。

## 串口变化

Y字段bit11为optical_online。在线时X字段改为8个过滤后光键松开位（bit0=X1，0=触发），不再是摇杆X ADC值；不在线时仍为ADC X。K仍报告板载4键。read-instrument-status.py解析为optical_online、optical_pressed_keys，同时保持原模式/音色字段。E/V仍是ADS状态，不把它们误称新模块错误码。
