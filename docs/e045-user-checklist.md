# E045烧录后的用户测试清单

Flash写入及校验成功，写后独立E045/6020；不再下载SRAM，保证下面的冷启动验证有意义。请安装APK0.11，原版界面不变。先做1–4并反馈，5–6可随后继续。

1. **完整冷启动：**音箱先调小。断开Dock、PCM、K230全部供电约10秒，再按原来先PCM、后Dock/K230顺序上电。按住S1+S2，按下并松开摇杆，再松开两键，只做一次；等待约20秒初始化。RCFG不算断电。确认能发声、有热点。USB接回电脑后告知，我可只读核对版本。
2. **手机先不连接：**光键单音按/松，至少四音和弦并逐个松开；保持一个音，摇杆左右听音高变化、上下听力度变化，再试捏合音量与手势高度亮度。手势本身不触发音符。
3. **手机连接后的重点回归：**连接FPGA-Instrument热点，APK0.11地址192.168.4.1:9000，音量先160、选风琴，持续按住一个手机键。捏合应仍改变音量，摇杆左右与手势高度仍有效；再将手机音量80/160切换。断开再连接后不应自动出现旧颤音，松开手机键不应残留持续音。
4. **四音色：**关闭效果，同一短乐句切电钢琴/风琴/弦乐/Bass。电钢琴有衰减、风琴持续、弦乐慢起音，Bass低音区试听。反馈是否能区分、是否出现非预期颤动、爆音或Bass明显偏弱；不能仅看界面音色名。
5. **硬件视听与效果：**S2切OLED波形/频谱/XY等页，确认随实际声音变化；S0短按切效果，分别听合唱、延迟、混响及松键尾音。S3锁存/曲谱和S0压力模式会造成持续音，测试后恢复关闭。
6. **App扩展闭环：**设置→直连扩展。下载12:20,16:20,19:20,-:10并回读，播放，断开手机后用S3检查LED脱机指引；重连，位置0映射12并弹第一键核对音高，再恢复0→0；点击录音后立即演奏，等128块、保存WAV并用播放器播放。

反馈格式：冷启动/本地光键和弦/手机捏合与摇杆/四音色/Bass/显示效果/曲谱映射录音，各项“正常”或具体异常。先反馈前四组即可；异常注明是否已连手机、按的音符/音区/音色和听到的现象。

这些功能测试不能替代同步仪器测量≤10ms/≤5ms和LRCK采样率，量化指标仍单独待验。视频最后按实际通过项目指导拍摄。
