# E045使用教程（原版自绘UI，热点直连）

## 版本与接线

E045已写入Flash并校验成功，独立读回E045/0x6020；完整断电自启动尚待用户验证。现在可以按下方步骤冷启动。使用[APK0.11](../mobile-companion/apk/instrument-companion-0.11-e045-direct.apk)；签名与0.10一致，可覆盖升级；原版自绘UI保持不变。

沿用已验证接线，不带电改线。PCM模块用现有独立USB供电，不把它的3.3V排针再次接入供电；模块共地，K230避免双路供电。音箱先调小音量；先PCM供电，再Dock/K230。电脑保持原网络，只有手机连接ESP热点。

## 启用与本地演奏

1. 启动后按住S1+S2，按下并松开摇杆，最后松开S1/S2；只做一次。等待1秒保护及约20秒外设初始化。重复组合会关闭外设。RCFG仅重配FPGA，不等于全系统冷启动。
2. 遮挡/触发光键并松开，先确认单音和释放；同时触发多键可弹和弦。光键和手机八键按四个音区覆盖C3–G5。
3. 保持一个音，再动手势：捏合识别值调有效音量，高度识别值调亮度。**手势本身不产生音符**；丢手后恢复非手势增益。不要用“手一移动没有声音”判断故障。
4. 摇杆左右弯音，上下改变力度。单按摇杆切电钢琴→风琴→弦乐→Bass。四音色是实时合成预设；Bass试听选音区1的低音，C4对照不能替代低音试听。

| 板载操作 | 功能 |
|---|---|
| S0短按/松开 | 效果：关→合唱→合唱+延迟→全开 |
| S1短按/松开 | 切换八键音区 |
| S2短按/松开 | OLED页面 |
| S3短按/松开 | 本地曲谱启动/停止 |
| S3按住约1秒 | 锁存开/关，松开光键后可保持音符 |
| S0按住约1秒 | 32音压力测试，提前降低音箱音量 |

板载S0–S3也会触发对应高音；模式动作在释放/长按判定后发生。手机连接后音色、音区、效果及音量上限由手机目标参数接管，优先在手机上修改；摇杆弯音和手势亮度仍保留，除非显式远程命令接管对应参数。

## 手机连接与演奏

1. 手机Wi-Fi连接`FPGA-Instrument`，密码`fpga-demo-2026`。提示“无互联网”时选择保持连接；关闭会自动离开此Wi-Fi的功能。
2. 打开APK的原版自绘演奏界面。设置地址`192.168.4.1`、端口`9000`，点击连接。连接状态、实际设备回传与目标设置要分别看待。
3. 音量先设160，选风琴或Bass，按住手机键，再测试捏合。实际增益≈手机音量上限×捏合增益；手机上限为0时，张开手也不会发声。
4. 八键支持多指，松开停止。手势/摇杆仍要在持续音符时听；依次试捏合音量、左右摇杆音高、手势高度亮度，再同时操作。
5. 断开再连接，确认没有自动出现旧颤音。界面波形是设备遥测，不是手机麦克风录音。

## 直连扩展

在原版演奏页点设置，再点“直连扩展 · 曲谱 / 键位 / 录音”，使用当前热点连接，无需公网中继。

- **曲谱：**输入`12:20,16:20,19:20,-:10`，点“下载曲谱并回读确认”。0=C3、12=C4、31=G5；时长单位10ms，示例前三音各200ms、休止100ms。回读成功后播放；断开手机后用S3验证LED脱机指引。曲谱断电不保留，重启需重传。
- **键位：**先松开演奏键，位置填0、目标填12，点“设置键位并回读确认”；音区1第一键应改成C4。恢复位置0→音符0。其余位置0..31同理。回读成功后仍要实际弹奏核对音高。
- **录音：**点“录制设备PCM并导出WAV”，弹窗会返回原版键盘，立即演奏并等128块收齐，然后选保存位置。是约0.7秒、8bit、单声道的FPGA数字短录音；不是音箱麦克风录音，不代表高保真连续录音。用播放器打开导出的WAV核对。

## 常见问题

- 有手势数字却不响：先保持光键或手机键，排除手机音量0、捏合值接近0、音箱输入/音量错误。
- 松键还响：关闭S3锁存、曲谱和S0压力测试；区分混响尾音与持续门控。
- 连接后捏合失效：先确认运行E045；若冷启动没有正常运行，请保留现象并反馈；用音量上限160与单音重试。
- Bass似乎不够低：切音区1，使用低键；当前32音范围C3–G5，不会自动把Bass降一个八度。
- 手机导出失败：确认保持热点连接、128块收齐，再选择保存位置。错误信息保留，不将发送成功当回读成功。
- 无热点/外设异常：先核对启用流程；本轮Flash已写入E045，可按完整冷启动流程检查。不要让电脑加入热点，不重刷ESP固件。

## 由用户执行的冷启动检查

代理已完成E045 Flash写入校验。现在可以关音箱音量，完全切断Dock、PCM、K230等全部供电，重新按原顺序上电并启用。核对版本、热点、单音、和弦、捏合、摇杆、OLED。E045已经固化但完整冷启动结果待你确认；仅拔一根线或按RCFG不算完整冷启动。结果反馈具体版本和现象即可。

## 公开热点版构建

安装Gowin Education 1.9.11.03及器件许可，在`firmware/e028-extension`目录用官方`gw_sh.exe tools/build_ap_public.tcl`构建。默认输出`build-public/instrument_e045_public`；可设置`FPGA_BUILD_ROOT`改变输出目录。不需要`FPGA_WEB_PRIVATE`、云服务账号或`cloud_config.v`。器件GW2A-LV18PG256C8/I7、27MHz，使用仓库既有CST/SDC。构建成功不等于已下载；最终下载要核对码流hash与设备。

当前App解析与真实板包回放证据见[APK0.11报告](../firmware/e028-extension/docs/e045-app011/README.md)，实际手机闭环仍待验收。
