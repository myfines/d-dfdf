# 作品简介（当前实测版本）

作品名称：基于 FPGA 的多维交互实时合成电子乐器

本作品以高云 FPGA 为实时音频计算核心，将八路光电感应、双轴摇杆与视觉手势结合，构建可脱离电脑演奏的电子乐器。FPGA 通过 HDL 实现独立声部振荡、ADSR 包络、实时变调、多声部混音和数字延时，并经 I2S 接口连接 PCM5102A 输出音频；声音由实时演奏指令逐样本生成，不依赖整段预录音频播放。

系统支持四声部复音、三种合成音色预设及多维表情控制：光键负责选音，摇杆控制弯音与明亮度，K230 提取手部关键点并通过串口传送捏合和位置参数，FPGA 完成音量与音色映射。OLED 展示 FPGA 生成的波形及状态；Android 应用通过 Wi-Fi 提供触屏演奏、参数调节、手势状态显示、键位重排和事件记录导出。视觉模块与手机仅承担交互和辅助控制，核心音频合成始终在 FPGA 中完成。

当前已完成光键、四声部混音、摇杆、手势、OLED、Wi-Fi 与 Android 应用的联调验证；另有32振荡器频谱测试模式。后续重点完善32路完整可控能力、脱机曲目引导及端到端延迟的定量验收。

说明：2026-10-23已完成E026 Flash写入、校验、断电自启动及光键/摇杆/手势功能验收。事件CSV不是音频录音；32测试模式不是32路自由演奏；尚不宣称≤10ms或≤5ms已实测达标。
