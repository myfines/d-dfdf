# K230 UART手势发送候选（2026-10-22）

状态：仅生成电脑端文件，未部署、未访问设备、未改FPGA、Android或Flash。Dock OTG保留供电，数据改用UART；不再要求FPGA USB host。

## 接口和接线

| 项目 | 候选约定 |
|---|---|
| 外设 | K230 UART1 |
| TX | EXPORT接口IO9，复用UART1_TXD/TX1 |
| RX | IO10不接、不配置其复用 |
| 串口 | 115200 baud，8数据位，无校验，1停止位 |
| 接线 | K230 IO9 → FPGA RX；K230 GND → FPGA GND |
| FPGA RX | 对方暂定PMOD1 M14，最终封装脚、连接器脚位及电气核对由FPGA侧完成 |
| 供电 | 继续Dock OTG → K230 Type-C；EXPORT 5V、3V3均不互连 |

亚博标准板YB-DKA02-V1.0说明书正面图片中，右侧EXPORT位于Type-C上方，该视角丝印从上到下为5V、GND、IO9、IO10。背面复用表为IO9 TX1、IO10 RX1。以实物丝印识别，不按线色或镜像后的插头序号接线。

**电平证据边界：**已核实TX映射，但目前找到的亚博UART PDF只泛指TTL可能为3.3V/5V；FPIOA PDF的“12：3.3v输出”描述电源脚，不能证明IO9高电平。尚无该板IO9电压实测或明确电源域原理图证据。接FPGA前确认IO9高电平符合FPGA输入电源域；不能把5V信号接入FPGA。电压不匹配需电平转换。供电能启动不代表信号电压已验证。

## 数据契约

复用docs/k230-gesture-protocol-v1.md的12字节包：A5 5A、版本01、递增回绕序号、valid、捏合BE16、纵向位置BE16、置信度、CRC16-CCITT-FALSE BE16。CRC覆盖2..9，初值FFFF、多项式1021。无换行、文本或额外握手。

原始检测置信度必须>=0.60；无手、多手、无效几何、HOLD和超过150ms的旧结果均发valid=0及零参数。沿用现有参数映射，捏合仍待标定。纵向位置取关键点5/17平均y，按640×480画面映射顶部0、底部1000。

发送线程目标50ms/包，不补发积压突发包。12字节在115200 8N1约占1.04ms。此前USB手势实测仅约7.49Hz；UART更换不能证明推理调度已达到20Hz。需板测实际间隔、CRC、序号及有效手势覆盖率。

底层API为machine.FPIOA().set_function(9, UART1_TXD, ie=0, oe=1, pu=1)及machine.UART(UART.UART1, baudrate=115200, bits=UART.EIGHTBITS, parity=UART.PARITY_NONE, stop=UART.STOPBITS_ONE)。使用UART.write(bytes)检查部分写入，失败停止发送并deinit，依赖FPGA既有250ms失联释放。没有应用层ACK。串口复位后序号从0开始，FPGA侧须确认失联后接受重新建立的序列。

IDE输出UART_GESTURE每秒摘要与原PINCH2记录；这些print走现有控制台，不写UART1。LCD、摄像头和模型流程保留。线程/API及错误清理行为尚未板测。
