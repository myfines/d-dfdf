# E037 操作步骤

1. 按现有接线：PCM独立USB供电、3.3V排针不接；模块共地；K230避免双路USB供电。先PCM、再Dock/K230。明显烫手立即全部断电。
2. 上电后应有未启用心跳。按住S1+S2，按下并松开摇杆，再松开两键；只做一次。等待1秒保护结束，八路模块初始化约20秒。重复组合会关闭外设。
3. 光键触发/移开演奏；摇杆左右改变音高、上下改变音色参数；K230捏合控制音量，手移开恢复本地控制。
4. 短按S0切效果组合，短按S1切八键音区，短按S2切OLED页，短按S3启停本地曲谱；单按摇杆切音色。S3长按切锁存，S0长按为32音压力测试。RCFG是重新加载，不能当演奏键。
5. 新Android入口：原演奏台上方“E037公网”。填正在运行的HTTPS中继地址和访问令牌；服务没运行时不能连接。配置和下载先松开所有键。
6. 曲谱示例`12:20,16:20,19:20,-:10`：C4/E4/G4各约200ms，休止约100ms。点下载，等FPGA完整提交回读，再播放。下载成功后可断网，用S3启停。重启需重新下载。旧版APK不具备新下载协议。
7. 录音前保持实际演奏，点击“录制并保存WAV”，保持网络等待128块收齐；Android10+保存到下载/FPGA。仅约0.7秒、8位低带宽短录音。紧急释放不排在录音下载之后执行。
8. 网页AI工具：instrument_keymap、instrument_song、instrument_recording；所有发送回执与实际回读分开，不能把relayAccepted当设备验收。
