# FPGA电子乐器工程简介／技术审阅交接

日期：2026-10-20。仓库：https://github.com/myfines/d-dfdf
赛题：2026高云赛题二《基于FPGA的实时多音色合成电子乐器引擎》。要求来源：https://www.gowinsemi.com.cn/university/match2026

## 当前系统
Tang Primer20K＋Dock（GW2A-18C），八路光电巡线模块作为光键、PS2双轴摇杆经ADS1015采集；FPGA HDL完成振荡器、包络、混音和短延迟，通过16bit I2S送PCM5102A，再接有源音箱。输出采样率46.875kHz。音频不是播放整段录音，不通过MCU/CPU软件合成。

当前已验证Flash为CF73光键安全启用版，码流SHA256：B6A4D22C1EEB8343C0C97870C45059BAA3F1198F758271A82BFA0C09FA07E547。更改后须核对版本，不将工作目录内任意最新.fs认作板上现有版本。部分根README和instrument_io/README保留早期快照；当前进展以docs/operations.md、competition-audit-20261018.md及对应原始日志为准。

## 请优先帮忙审阅
1. 光键读取/I2C轮询、消抖、声部分配、包络、I2S的总延迟预算，确定≤10ms可达性和测量方案。
2. 四声部释放/重触发及TDM状态隔离；32库如何完善为可独立调频和包络的合规合成能力。
3. 两种乐器音色的合成方案、第三表情维度、包络/混音定点位宽和削波风险。
4. 曾发生GW2A大芯片30秒内烫手并失声，断电后恢复，后续短时演奏正常；根因未明。检查约束、I/O电平/争用、供电与外设反灌、活动率；无实测温度电流，不预设为单纯散热问题。

八路模块标5V脚目前按用户选择接Dock3V3，厂商额定兼容未确认。PCM独立USB供电，排针+3.3V不接，信号共地。不要未经电气核对直接改接5V逻辑。
