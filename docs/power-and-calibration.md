# 独立USB供电、校准与断电说明

2026-10-12。当前系统有Dock USB-JTAG、PCM USB-C、ST-Link USB三个供电入口。杜邦信号全接时，某一端断电而另一端仍有电可能经信号/上拉反向供电；不能把某个USB先后顺序说成无风险或热故障已解决。此前“固定先PCM后Dock”的说法不能作为全部新增模块场景的安全保证。

当前只做独立八路模块校准：
1. 先拔掉Dock、PCM、ST-Link全部USB供电，确认灯灭。所有杜邦插拔均在全部断电时做。
2. 暂时断开巡线模块到T9/P9的SCL/SDA两根信号，其他地线可保留。
3. 仅插ST-Link USB，给巡线模块5V/GND，Dock/PCM不供电；按专用说明等待20秒并做黑白校准。
4. 校准完拔掉ST-Link USB，确认模块灯灭。之后需要接回SCL/SDA也在此全断电状态下做。
5. 当前FPGA曾报告快速烫手，先核对电平、电源与温度，不能直接长期烧录试玩。将来联调优先经核实的统一/受控供电，避免任何只一端有电的长时间状态；没有验证输入掉电容限时，不给独立USB固定顺序的安全承诺。

拆线原则：停止烧录/读串口操作，关闭所有电源/拔完全部USB，确认灯灭，再拆信号线；如果完整拆除，GND最后拆。不要靠先拔一根GND来断电，不要在一端仍有电时插拔信号杜邦线。

课题适配依据：https://www.gowinsemi.com.cn/university/match2026 。选题二允许光电感应等自研交互方案，至少2独立可控演奏维度；音频全FPGA HDL逐样本生成，至少4复音，支持变调/ADSR/混音/I2S，不播放预录音频。八路光键选音/触发+摇杆X/Y符合这一设计方向；传感器板MCU只采集/传输动作数据，不代替FPGA生成音频。八输入四复音满足复音数量的设计门槛，不等于已完成所有实物指标。总延迟<=10ms、真实谱峰、稳定交互与热可靠性仍需现场/仪器验证。
