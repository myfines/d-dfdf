# App0.15安装与简化曲谱操作

[下载APK](../mobile-companion/apk/instrument-companion-0.15-e049-easy-score.apk)，版本0.15-e049-easy-score／versionCode15。包含0.14合唱/混响修复；与0.13/0.14同签名，正常覆盖安装，不用卸载或清数据。FPGA仍E049，不需要重烧。

## 曲谱最短操作

1. 手机连接FPGA-Instrument，进入App连接，再打开设置→直连扩展。
2. 新安装已填入示例曲谱；更新安装会保留原曲谱。**不需要联网时，直接点击“下发曲谱到FPGA并回读确认”**，等回读完成后播放。
3. 想实际在线下载，地址已经填好，点“下载曲谱（默认示例）”即可；网址被清空也自动使用示例地址。仍支持替换为自定义HTTP/HTTPS文本曲谱。
4. ESP热点不提供互联网。若手机当前不能上网，先切到可上网网络下载，再切回ESP热点连接、下发；下载失败不会清空现有曲谱，不假装成功。

示例公网地址：https://cdn.jsdelivr.net/gh/myfines/d-dfdf@e031-web-control/docs/demo-score.txt 。本轮电脑HTTP200读取47字节，与内置示例一致；不是本轮手机联网验证。
