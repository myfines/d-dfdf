# 单电源与不依赖人工上电顺序的目标方案

用户明确要求减少外接电源、无需记忆上电顺序。此前“各板独立供电、避免单侧断电”仅是临时调试限制，不满足成品要求。

## 目标拓扑

一个稳压5V电源，经一个总开关和分路保护，并联送往Dock输入、K230 Type-C输入、现有PCM模块USB电源输入。各板不经另一块开发板转供，共地，电源线分别回到分配点；不能把多个适配器输出直接并联。电源额定值应按全部实际负载峰值与线损计算，5V4–5A可作待核选型范围，不是已测需求或保证。确认PCM实物USB端为5V输入后才纳入接线。音箱若有其他额定供电，另行核验，不能默认改5V。

K230要求5V输入，不能从Dock3V3供电，也不能假设K230标3V3脚可替代主电源输入。FPGA Bank3.3V仅表示信号标准；整块Dock也不改为直接向3V3网络注电。

## 顺序无关需要的电路

共用开关不等于各板电压同时建立或同时掉电。UART信号用双电源、掉电隔离的单向缓冲器：A侧电源取发送板的3.3V，B侧电源取接收板的3.3V，两3.3V网络不短接。TI TXU0101资料明确：任一VCC低于100mV或断开，输出高阻，支持Ioff和VCC disconnect。不是仅靠串联电阻或泛称“电平转换模块”保证。

K230 TX->FPGA RX优先一个方向，反向需要另一通道。现有FPGA->PCM的I2S BCLK/LRCK/DATA也须按实际电压、时序与掉电隔离要求检查/选型；只保护新增UART不能称全系统顺序无关。多通道器件型号尚未选定。OE、默认状态、去耦、上电时输入状态仍按完整数据手册设计，不根据功能摘要直接接线。

调试时电脑USB与外部供电重叠需有明确VBUS隔离/电源选择，不能用普通Y线并联。只断USB红线或使用所谓数据线不一定能完成Type-C连接/枚举，具体方案尚未定型。

## 资料证据与限制

- 本地官方Dock3713 Rev1.1 PDF已核对：OTG J8 VBUS直连+5V、CC下拉，无J8专用VBUS限流/反向隔离开关；有5V不等于已验证能给额外负载供电。
- 亚博本地供电说明：5V输入，标准版AI约0.6A、带屏豪华版约0.8A，是参考工作电流，不是启动峰值。
- TI TXU0101：https://www.ti.com/lit/ds/symlink/txu0101.pdf ，本次直接读取官方PDF，确认VCC isolation/VCC disconnect与Ioff说明。
- TI SN74LVC1G125：https://www.ti.com/lit/ds/symlink/sn74lvc1g125.pdf ，本次确认Ioff/partial-power-down；单电源缓冲器仍需额外分析发送端断电输入状态，不冒充完整双电源隔离方案。
- 外部网络搜索工具返回错误，Sipeed wiki请求超时；未获取可核验的他人整机同款供电案例，不声称他人已验证此组合。以上是官方电路与器件规格支持的设计建议。

尚未实装、测电流或执行上电，不宣称已解决历史FPGA发热故障。下一步确认实际电源额定值、PCM板供电入口和Dock硬件版本，完成供电分配/接口隔离设计再接线验收。目标验收包含任一分支先断/后开、USB插拔时不反灌，以及上电静音/串口无效包回退。
