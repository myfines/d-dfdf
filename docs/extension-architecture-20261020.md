# ESP/OLED/K230扩展方案预核（2026-10-20）

## 合规边界
官方选题二 https://www.gowinsemi.com.cn/university/match2026 ：实时视觉反馈应由FPGA硬件逻辑生成；手机联动描述为“可搭载蓝牙模块”，不能读成所有无线链路强制蓝牙。结合用户FAQ A2/58/68，WiFi用于参数配置/曲谱下载等辅助控制是合理方案，但只能称WiFi联动，不冒称已完成蓝牙条目或保证同分。

建议链路：ESP-01S仅网络透传；FPGA HDL负责波形抽取/坐标/像素与OLED I2C或SPI驱动，优先OLED直接接FPGA。若ESP软件做频谱/布局/绘图，则不把该部分当作纯HDL实时视觉成果。OLED状态菜单不等于演奏可视化，须展示随真实合成采样变化的波形/音符活动，可后加节奏曲目指引。

ESP-01S是ESP8266 WiFi模块，不含蓝牙；新增无线功能不应承担音频合成或基础演奏路径。独立核对3.3V供电峰值预算，不直接给现有Dock电源增加未知负载。

蓝牙成本：本轮搜索没有取得可核验的国内单件在售最低结算价，不声称全网最低。JDY23 BLE/JDY31 SPP等低价裸模块与带底板/焊排针版本不可直接比较；HC05手册只说明SPP串口，不等于音频蓝牙。ESP32-C3有WiFi+BLE的低价替代方向，但开发固件成本也要计入，不必为可选蓝牙立即购买。

## 64GB TF卡
本轮Get-Disk仅发现系统NVMe，没有读卡器/目标卡可识别；未格式化、未写镜像。K230需亚博匹配启动镜像，不能将原FPGA卡内文件复制一下便认为可启动。卡容量64GB本身不证明兼容，须核对烧录教程、镜像分区和实际启动。

执行顺序：全断电取卡→读卡器接电脑→确认容量/物理磁盘身份→备份原卡文件及必要分区→确认可覆盖目标→写匹配亚博镜像→独立USB供电启动/摄像头例程→串口自检→手势参数→FPGA SRAM联调。保留原Flash，卡未备份前不做破坏性写入。不保证未经测试的硬件和模型必然完成，按阶段保存日志与证据。
