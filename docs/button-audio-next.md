# 板载按键与芯片到货前的音频工作

日期：2026-09-29。板卡照片与当晚实物反馈已纠正最初的按键命名错误：左侧底部是 **RCFG**，不应按位置把它称作 S4 演奏键。按下 RCFG 后音频消失。随后独立 SRAM 灯测确认 S0 对应的 T10 输入有效；打开 SSPI 双用途后重新构建音频，用户确认 S0–S3 均有音。具体命令与结果记录在 `docs/operations.md`。

## 引脚与现有程序

| 实物/约束 | 已确认的事实与边界 |
|---|---|---|
| S0 / T10 | 独立 LED 探针的 N14 随 S0 按压亮灭，心跳 LED 持续；Gowin 布局报告为 T10、LVCMOS33、3.3 V。新版音频中用户听到 S0 的 C5。 |
| S1、S2、S3 | 旧版和新版音频都由用户逐个试听确认有声；当前约束为 T3/T2/D7，LVCMOS15、1.5 V。 |
| RCFG（左侧最下方） | 用户确认先前误称的“S4”就是此键。板卡照片有 RCFG 丝印；原理图含独立低有效 RECFG 信号。它不是已验证的演奏键，按下后不再有本音频程序的声音。 |
| 当前 `audio_keys` 约束 | `btn_n[0..3]` 使用 T10/T3/T2/D7。只把 SSPI 设为普通 IO；JTAG、MSPI、RECONFIG_N 保持专用。 |

依据：[Sipeed 官方约束](https://github.com/sipeed/TangPrimer-20K-example/blob/main/Litex/sipeed_tang_primer_20k/src/sipeed_tang_primer_20k.cst)、[官方复位脚说明](https://github.com/sipeed/TangPrimer-20K-example#reset-pin)、用户先前提供的板卡照片，以及其实物试听反馈。当前版本按键逻辑是最低键优先的**单音**；四路逻辑输入不等于四个已验证的实体演奏键，更不等于四复音。

## RCFG 后为何仍能看到灯响应

灯闪和按键灯有反应，只能证明 FPGA 上某份逻辑在运行，不能证明仍是刚下载的 SRAM 音频工程。Flash 先前读到非空出厂内容；按 RCFG 后可能切回其中的演示逻辑。因为未读取当前配置的唯一标识，这仍是符合证据的解释，不能当作已证实的 Flash 内容。此诊断不要求再按 RCFG。

## 芯片到货前的工作顺序

1. 不把 RCFG 作为演奏键。S0/T10 的 SSPI 双用途已经在 SRAM 音频码流中验证；不改动 JTAG/MSPI/RECONFIG_N 的专用设置。
2. 基于现有 PT8211 耳机口完成四个独立 DDS 声部、各自 ADSR 与限幅混音；当前最低键优先逻辑要改成允许并发发声。
3. 先用 HDL 仿真和自动测试模式验证四声部，再用已确认的 S0–S3 实物键逐个与组合试听；当前单音不能称作四键和弦。
4. 后续外接按键板用于更舒适的演奏扩展，不再是实现基础四键输入的前提。
5. MCP3008、摇杆和外接标准 I²S DAC 到货后才接线。当前 PT8211 用于音频开发，不把它的 LSBJ 接口冒充为最终 I²S 输出。
