# 板载按键与芯片到货前的音频工作

日期：2026-09-29。板卡照片与当晚实物反馈已纠正最初的按键命名错误：左侧底部是 **RCFG**，不应按位置把它称作 S4 演奏键。按下 RCFG 后音频消失；重新下载同一音频码流到 SRAM，S1、S2、S3 均再次发声。此行为符合重配置后原 SRAM 音频设计被替换的解释，但尚未回读确认随后运行的究竟是哪份 Flash 内容。实际下载命令与结果记录在 `docs/operations.md`。

## 引脚与现有程序

| 实物/约束 | 已确认的事实与边界 |
|---|---|---|
| S0 | 用户此前反馈未发声。官方示例含 T10 输入，且说明 T10 为复位/SSPI 双用途脚；但此处没有证明实物丝印 S0 就接 T10。当前音频工程没有约束 T10。暂不尝试改作演奏键。 |
| S1、S2、S3 | 2026-09-29 22:53 再次下载到 SRAM 后，用户逐个试听确认三键都能发声。 |
| RCFG（左侧最下方） | 用户确认先前误称的“S4”就是此键。板卡照片有 RCFG 丝印；原理图含独立低有效 RECFG 信号。它不是已验证的演奏键，按下后不再有本音频程序的声音。 |
| 当前 `audio_keys` 约束 | `btn_n[0..3]` 分别使用 T3/T2/D7/C7；这是逻辑管脚分配，不应无依据地直接写成实物丝印 S1–S4。 |

依据：[Sipeed 官方约束](https://github.com/sipeed/TangPrimer-20K-example/blob/main/Litex/sipeed_tang_primer_20k/src/sipeed_tang_primer_20k.cst)、[官方复位脚说明](https://github.com/sipeed/TangPrimer-20K-example#reset-pin)、用户先前提供的板卡照片，以及其实物试听反馈。当前版本按键逻辑是最低键优先的**单音**；四路逻辑输入不等于四个已验证的实体演奏键，更不等于四复音。

## RCFG 后为何仍能看到灯响应

灯闪和按键灯有反应，只能证明 FPGA 上某份逻辑在运行，不能证明仍是刚下载的 SRAM 音频工程。Flash 先前读到非空出厂内容；按 RCFG 后可能切回其中的演示逻辑。因为未读取当前配置的唯一标识，这仍是符合证据的解释，不能当作已证实的 Flash 内容。此诊断不要求再按 RCFG。

## 芯片到货前的工作顺序

1. 不把 RCFG 作为演奏键；保留 T10 的双用途设置，暂不为了凑键位修改它。实体 S0 的电气映射另行核对。
2. 基于现有 PT8211 耳机口完成四个独立 DDS 声部、各自 ADSR 与限幅混音；当前最低键优先逻辑要改成允许并发发声。
3. 先用 HDL 仿真和自动测试模式验证四声部；在实物上只用已确认的 S1–S3 试听，不把三键体验声称为四键和弦。
4. 第四个演奏输入由后续外接按键板补齐；必要时另做仅 LED 显示 GPIO 的 SRAM 诊断，确认剩余逻辑脚对应的实体按键。
5. MCP3008、摇杆和外接标准 I²S DAC 到货后才接线。当前 PT8211 用于音频开发，不把它的 LSBJ 接口冒充为最终 I²S 输出。
