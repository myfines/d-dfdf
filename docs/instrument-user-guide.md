# 现有硬件完整功能版：操作说明

硬件保持 Tang Primer 20K Dock、ADS1015、双轴摇杆、PCM5102A，不增加按键。RCFG 是重配置键，不能拿来演奏。最新版在 SRAM/Flash 的实际状态以 README 与 operations.md 最后记录为准。

## 接线和供电

| 模块脚 | 接点 |
|---|---|
| ADS VDD / GND | Dock真实3V3 / GND |
| ADS SCL / SDA | T6 / T7 |
| ADS ADDR | GND（地址0x48） |
| ADS A0 / A1 | 摇杆VRX / VRY |
| 摇杆GND / 标+5V供电脚 | GND / Dock真实3V3 |
| 摇杆SW | T8 |
| PCM DATA / BCK / LRCK | P6 / R8 / P8 |
| PCM GND | 与Dock共地 |
| PCM电源 | USB-C入口供电；排针+3.3V不接 |
| 音箱 | 有源音箱供电，PCM 3.5mm接其AUX/LINE输入 |

Dock 1号核心板使能拨码必须ON。按背面丝印定位PMOD，勿按照片镜像猜引脚。

## 演奏和组合操作

短按：按下摇杆按钮后，在1秒内松开。长按：持续约1秒，直到心跳灯速度变化。组合操作先按住指定S键，再按摇杆，完成后松开。

| 操作 | 功能 |
|---|---|
| S0–S3 | 四声部独立演奏、同时按键混音 |
| 摇杆X | 连续弯音，中心有死区 |
| 摇杆Y | 三角/正弦预设的波形亮度；锯齿拨弦预设波形固定 |
| 不按S键，短按摇杆 | 依次切换三角合成音、正弦合成音、锯齿拨弦音 |
| 按住S0，短按摇杆 | 切换音符分组，共覆盖12个半音 |
| 按住S1，短按摇杆 | 切换正常/低八度 |
| 按住S2，短按摇杆 | 开关短延迟效果 |
| 松开S键，长按摇杆 | 进入/退出ADSR编辑 |
| 按住S0+S3，长按摇杆 | 进入/退出32声部频谱测试模式 |

三组按键从S0到S3：

- 第0组：C5、D5、E5、G5（默认，与此前四键版相同）。
- 第1组：C#5、D#5、F5、F#5。
- 第2组：G#5、A5、A#5、B5。

低八度设置对上述整组生效。正常演奏仍只有4个同时按住的键；32声部模式是容量/频谱验证，不等于四键能独立操作32个音符。

## 包络编辑

进入编辑后，普通演奏会淡出并静音。按住S0/A、S1/D、S2/S、S3/R之一，同时上下移动摇杆Y修改对应参数。编辑值在松开参数键后保留；松开全部S键再长按摇杆退出，按键恢复演奏。新参数在下一次触发音符时锁存，不把正在释放的旧声部突然改掉。

A起音步长1–16；D衰减间隔4–64帧；S保持电平32–242（满幅256）；R释放间隔2–32帧。向Y高端移动使A更快、D/R更慢、S更高。时间还依赖峰值到保持电平的差值。切换音色会恢复该音色预设包络，编辑值不跨断电保存。锯齿拨弦预设S=0，长按键后自行衰减到静音属于预期。

## 测试和指示

N16：普通演奏慢闪、编辑较快闪、频谱测试快速闪。N14：ADS有效数据状态。LED0/1常亮时优先核对核心板使能；它们不是本工程的模式灯。

测试模式自动产生129、160、191……1090Hz，共32个不同频率的正弦声部，关闭演奏键、弯音和延迟效果。听起来是混合声音，不用于音质判断。频谱仪应检出对应的32个基频；不要将谐波数量当复音数。退出方式与进入相同，退出后松开S键等待释放/尾音结束。

模式切换先淡出到零再淡入。延迟为2048帧约43.69ms，输出75%干声+25%延迟声，不带反馈；松键后可能有释放和尾音。所有混音按最坏情况预留余量，不超过约四分之一数字满幅，因此单键不会很响。用音箱自身音量调整试听响度。

## 复现和鉴定边界

仿真：运行 instrument_io/run_tests.ps1。32声部仿真数据生成后，运行 scripts/verify_spectrum32.py，输入 E:/gaoyun/tools/smoke/spectrum32.csv。构建：gw_sh.exe instrument_io/build.tcl。检查源码、时序、SHA256和烧录记录均在logs。

当前输出46.875kHz、16bit I2S。数字测试包括模式、13组逻辑/协议/波形/包络/混音/整机验证和32基频分析；这些不代替DAC模拟频谱、<=10ms真实端到端延迟、音质和操控稳定性的仪器验收。三预设是合成音色，不宣称模拟真实钢琴等乐器。

Flash采用已成功的官方GAO-Bridge操作37。使用串口检查后，先关闭串口并重新拔插USB再烧录。必须有Program and Verify flash successfully，再完整断电检查自启动，不能只看100%。稳定旧码流备份在 E:/gaoyun/releases/instrument-verified-3CB9.fs。
