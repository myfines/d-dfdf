# E047＋App 0.12 使用与分步验收

手机安装 `mobile-companion/apk/instrument-companion-0.12-e047-expression.apk`，可覆盖0.11；原版自绘演奏主界面保留。板卡继续使用已烧录E047，不需要为本次App升级重新烧录。手机实际安装与闭环尚未验收。

## 连接与基本演奏

电脑保持原网络。手机连接 `FPGA-Instrument`（密码 `fpga-demo-2026`），App连接 `192.168.4.1:9000`。外设启用、接线和冷启动沿用 [使用教程](e045-user-guide.md)。先把音箱音量调小；手机音量可先160。按住音符再做手势，手势本身不触发声音。

先测同一音符的电钢琴、风琴、弦乐和Bass；再按住四键并逐个松开。分别确认捏合音量、高度亮度、摇杆弯音，连接手机时也应有效。断连后等最多5秒，再确认本地演奏；重新连接时颤音和32声部测试默认关闭。

## 新增入口：设置 → 直连扩展

1. **颤音**：输入0..255并应用，按住音符试听；0关闭。此功能调制音高，不是切换音色。当前状态帧没有颤音深度回读，界面只报告发送请求。
2. **ADSR**：A/D/R索引0..15，越大变化越慢；S保持电平0..255。默认示例9/12/160/13。应用后等待FPGA回读确认，再重新触发音符。S很低时持续音会很小；“恢复四音色原厂包络”可回退并回读确认。自定义配置作用于后续触发声部，断开App不会自动清除，板卡复位或主动恢复才取消。
3. **效果器**：独立勾选合唱、延迟、混响，再应用。主界面延时开关只改变延迟位，合唱与混响在扩展页关闭；不以发出命令代替实际试听。
4. **OLED**：选择波形、16带频谱、立体声李萨如、曲目指引或系统状态，再切换。请查看实际OLED；手机波形不是OLED验收证据。
5. **32声部测试**：降低音箱音量后启动；完成观察后点击停止。断连最迟5秒释放。测试启动请求不证明32声部可闻数、采样率或吞吐量，仍需配套测量。

## 在线曲谱 → 脱机指引

支持从HTTP/HTTPS最终文本网址下载UTF-8曲谱，非网页、MIDI或音频。格式如 `12:20,16:20,19:20,-:10`：0=C3、12=C4、31=G5，时长单位10ms，最多64事件，文件最多8192字节。不跟随重定向，不接受网址中的账号密码；无内置互联网曲库搜索。

手机先在有互联网的网络下打开扩展页，输入网址，点击“从互联网获取曲谱并保存到手机”；下载校验成功后缓存保留。若ESP热点没有互联网，先下载再换回热点连接App。点击“下发曲谱到FPGA并回读确认”；确认的是曲谱就绪与事件数，不是每个事件逐字回读。随后播放/停止，或断开手机用板上S3操作，观察LED节奏指引。FPGA曲谱断电丢失，手机缓存不丢失。也可继续手工输入。

示例文本见 [demo-score.txt](demo-score.txt)，可放在可访问的静态文本网址。网址须由使用者提供；本轮本机HTTP下载测试通过，不代表手机公网下载已验收。

## 映射与录音

松开演奏键，设置位置0→12，等待回读后按原位置试听；测试结束恢复0→0。录音按钮会关闭对话框返回主键盘，立即演奏，接收完整128块后选择WAV保存位置，再用手机播放器播放。录音约0.7秒、8bit、单声道，仅用于监测；合成发声不使用预录音频。

## 赛题验收保留项

软件入口已补齐不等于整机合格。仍需完整断电自启动、真实手机连接/断连组合控制、四音独立释放、曲谱/映射/录音实际闭环、OLED/LED/效果试听。基础≤10ms、拓展≤5ms/抖动及实际LRCK采样率须同步仪器测量。视频最后按实际已验项目拍摄；FAQ103继续暂缓。
