# K230与Primer 20K Dock连接预核

2026-10-21，仅查资料，未接线或给FPGA新增负载。

依据：本地官方 `E:/gaoyun/docs/Tang_Primer_20K_Dock-3713_Schematics.pdf`（Rev1.1，USB PHY页标7/9，PDF第5页）；Sipeed官方 https://wiki.sipeed.com/hardware/en/tang/tang-primer-20k/primer-20k.html ，原理图入口 https://dl.sipeed.com/shareURL/TANG/Primer_20K/02_Schematic 。已查看USB PHY电路图像。

- J8 USB数据线连接U6 USB3317，通过ULPI连接FPGA；PHY本身不提供USB主机枚举、CDC串口驱动或UART桥。若走USB需另行实现主机控制器、设备协议并确认K230暴露接口，不是插线即通。
- J8 VBUS标为+5V，直接连接板上5V网；GPIO 3.3V不代表整板没有5V。该页没有显示专用受控限流的VBUS输出开关，CPEN未接；CC1/CC2默认各5.1k下拉，SW2控制ID支路，不应理解为已经完成Type-C源端供电角色切换。
- 不能仅凭+5V网络宣称可稳定给K230供电。亚博本地供电说明：标准版AI约0.6A、带屏版约0.8A；启动峰值、Dock供电来源/线缆/总电流预算未量测。用户实物存在屏幕，不能继续只按标准版无屏判断负载。
- 本地图纸调试器为BL702，工程历史设备记录出现FTDI；实物修订版尚待核对，图纸结论不可冒充逐板实测。没有执行USB互连或电源改动。

建议：K230继续独立5V USB供电；使用经引脚与I/O电压核验的3.3V TTL UART，K230 TX→FPGA空闲RX输入，GND→GND。仅发送视觉参数时两条线即可；需要回传再增加FPGA TX→K230 RX。不连接两板5V/3V3电源，不把UART接USB D+/D−或RS232口。FPGA接收端须增加同步、校验、序号、超时和限幅。

原电赛main配置K230 GPIO9/10为UART1 TX/RX，只是软件线索，不是已确认的排针接线图。最终针号须核验亚博实物丝印/FPIOA及当前Dock CST，避开音频、光键、摇杆、OLED/ESP和调试UART占用。当前没有指定可直接接的FPGA管脚。

FPGA历史快速发热失声根因未明，本阶段不通过给Dock增加K230负载来试验。USB共用供电若将来需要，优先由满足总功耗的独立5V电源分别供电，需检查两板供电入口与防反灌设计。
