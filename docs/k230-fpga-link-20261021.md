# K230与Tang Primer20K Dock连接预核

2026-10-21，仅资料核对，未接线、测电压/电流或改FPGA。

## 证据与结论

- 本地官方原理图 `E:/gaoyun/docs/Tang_Primer_20K_Dock-3713_Schematics.pdf`，3713/Rev1.1/2023-09-12，PDF第5页（图框USB PHY，Id7/9）：J8 VBUS直接接+5V；R38/R39各5.1k把CC2/CC1下拉到GND；D+/D-经R40/R41接USB3317，USB3317通过ULPI接FPGA BANK7。SW2控制USB_ID，不能提供Type-C CC源端声明，也不是VBUS电源开关。
- 图上未见J8专用VBUS限流/反向阻断电源开关。+5V与其他板内负载共网；不能由此声称可稳定给K230供电。PDF第2页F1 300mA在BL702局部3.3V支路，不是J8供电额定值。
- USB OTG可作为需另行实现协议的USB方向，USB3317只提供PHY；K230 USB虚拟串口要求相应主机枚举/传输/驱动，现有音频RTL未验收该功能，不能插线即称UART通信。
- FPGA GPIO 3.3V是逻辑电平，Dock同时有+5V电源网。不能用GPIO或3V3脚供K230。
- 亚博本地供电说明：标准版AI约0.6A，豪华带屏约0.8A，5V USB供电。当前实物有屏且屏幕曾显示hand，不再仅凭“标准版”名称估算负载。最终电源预算应按实物峰值与线损核验。
- 推荐K230保持独立USB供电（调试时电脑USB3，脱机可用足额5V适配器），FPGA按原供电；仅连接UART信号与GND。不把两板5V或3V3电源网相连，不在双供电情况下直接互插两板USB。

## UART候选接法，待最终引脚/电平核验后执行

亚博说明书标准版第3张：EXPORT四针含5V/GND/IO9/IO10，背面标IO9=TX1、IO10=RX1；原电赛源码也配置UART1 GPIO9/10。不按线色或照片方向直接猜物理针序。

| K230 | FPGA |
|---|---|
| EXPORT GND | GND |
| IO9 / UART1 TX | 新选的空闲3.3V Bank GPIO，约束为UART RX |
| IO10 / UART1 RX | 可选：新选空闲3.3V Bank GPIO，约束为UART TX |
| EXPORT 5V / 板上3V3 | 不接 |

优先单向TX+GND发送手势参数，115200/8N1。两侧信号须确认为3.3V CMOS/TTL；当前文档图仅确认引脚复用，EXPORT信号电平仍需匹配实际板型资料或在独立供电下测TX空闲高电平。FPGA并非所有Bank都是3.3V，禁止直接选1.5V Bank或复用已有输出/下载器UART驱动的网络。不指定未经占用检查的实际FPGA脚位。

连线全断电后进行，运行时两侧都供电；避免单侧断电另一侧TX反灌。既往FPGA发热失声根因未明，资料预核不授权以新增负载上电来排障。

## 2026-10-21 补充：Dock OTG主机实装先例
- 本次成功访问官方文档与GitHub。官方USB例程：https://github.com/sipeed/TangPrimer-20K-example/tree/main/USB ，Readme明确FPGA烧入后接电脑出现COM，为USB设备端，不是可连接K230的主机实现。
- 第三方项目：https://github.com/kami4ka/tang_computer ，README报告同款Dock USB3317经6-pin FS/LS serial mode + LiteX OHCI驱动USB键盘，使用Type-C公转USB-A母OTG适配器；文档称VBUS硬接+5V无需额外飞线。实现说明：https://github.com/kami4ka/tang_computer/blob/main/docs/usb3317.md 。这是作者报告的键盘主机先例，未在本地复现，不代表现有音频RTL已具备USB主机或K230通信能力。
- 修正表述：OTG硬件不是完全不能供电/当主机；USB单线供电+数据有实现路径，但要核验电源余量/线缆角色并另做USB主机与K230实际接口协议。现有CanMV通过0x30调试协议访问，不能直接等同普通TTL串口。官方设备端COM回显例程无法直接替代主机端。
- 用户报告历史K230上电带起整机，可能经USB共享5V网或信号保护路径回供，具体历史连接未知，不认定为安全供电验证。本次只读联网，无硬件操作。初次猜测官方仓库TangPrimer-20K返回404，随后找到正确官方TangPrimer-20K-example。

## 2026-10-21 再核同款OTG供电+通信案例
- 再次读取https://github.com/kami4ka/tang_computer 的README与gateware/usb_host.py。作者明确写键盘经USB-C公转USB-A母OTG适配器接Dock，VBUS硬接+5V无需供电飞线；README有键盘枚举/屏幕交互照片。源码包含USB3317 serial-mode初始化、LiteX/SpinalHDL OHCI集成，主机由Linux ohci-platform驱动。这是同口供电+数据的作者报告先例，本机未复现。
- 差异：该方案为FS/LS主机，不是可直接代入现有音频RTL的USB串口核；K230的USB速度回退、复合设备接口/CanMV调试协议和电流预算均未验收。README还称显示活动时有输入受影响，供电Hub有帮助，不能当稳定成品证据。
- 官方Sipeed/TangPrimer-20K-example/USB仍是设备端COM回显。补充GitHub仓库检索"Tang Primer" K230、"TangPrimer" CDC host等无结果，不代表全网不存在；当前未取得同款Dock直连亚博K230并同时供电/传参的可核验案例。
- 结论：OTG单线供电+通信可作为工程验证目标，不能仅插转接头立即获得现有UART手势功能。保留Flash及音频设计，只读研究，未接线、改电源或烧录。
