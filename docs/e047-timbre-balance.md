# E047电钢琴与Bass音量修复候选

用户反馈：手机键和光键的电钢琴/Bass都接近听不见；其他项目尚未确认。两种输入共用合成通路，不能归咎于App。旧数字C3保持测试中电钢琴RMS172、风琴1211、弦乐877、Bass836，电钢琴低约17dB；旧C4 RMS不能代表用户音箱听感。

## 改动与验证

- 电钢琴保持包络9000→45000，保留其起音/衰减和原谐波结构；原保持量不足是可复现问题。
- Bass保持36000→50000，谐波权重176/16/0→160/56/24，保留基波主导，同时增加小音箱更容易重放的上方分量。该改动需用户音箱试听，不能仅凭RMS证明主观响度。
- 不改风琴/弦乐、不改总混音增益、不加隐式颤音；峰值包络上限、Q16乘法、宽位混音及最终饱和逻辑保持。
- 先建立相对电平回归并失败，再修改；C3稳态数字RMS变为电钢琴860、风琴1211、弦乐877、Bass1145。此测试先启动音符，再将包络置为生产预设保持量，明确是稳态诊断，不冒充完整ADSR起音测试或声学验收。33项既有回归另行通过，平衡检查已加入默认套件。
- 完整E047构建27MHz约束通过：Fmax27.430MHz、setup/hold TNS0。临时E048探针43.351MHz，使用本次生产synth/FX/I2S，输出衰减4倍供电脑录音。

## 板上模拟录音

首轮电脑输入未接音频线，音量比例校验失败；用户随后明确“刚才没接，现在接了”。首轮标为无效并保留，不能拿环境录音分析音色。

重新接线后的真实WASAPI RAW采集：C4干声电钢琴约-15.75dBFS、风琴-12.93、弦乐-15.66、Bass-13.31。电钢琴比风琴低2.82dB、Bass低0.39dB；较先前同条件RAW记录，电钢琴提高约12.96dB、Bass约2.53dB。四段测量没有近满幅削波，但不外推为任何复音/音量下都无削波。

半音量约-5.97dB、四分之一-11.66dB、恢复误差-0.006dB，幅度控制健全性通过。保留一次RAW discontinuity记录，不把它用于低抖动验收。测量是探针C4干声，不替代实体光键/手机/手势和用户音箱听感。

## 当前板卡与用户下一步

探针已结束，完整E047已恢复SRAM，独立读回E047/0x6020。Flash仍E045，断电会回旧版；本轮不覆盖Flash，先核对用户音箱听感。请重新按S1+S2加摇杆组合启用外设，等初始化后，在相同音箱音量、手机音量160、无手势衰减、关闭效果条件下，重触发同一短旋律比较四音色；Bass同时试低音区与C4。反馈电钢琴/Bass是否够响，是否出现爆音/失真。

其他赛题项目仍按原清单待验，不能根据“其他暂时没怎么看出来”标为通过。E045交付包保留回退用途，当前不应将旧包直接作为音色问题已解决的最终版。
