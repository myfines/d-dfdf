# 电子乐器赛题差距清单（2026-10-12）

依据：https://www.gowinsemi.com.cn/university/match2026 ，选题二基础、拓展、现场验证要求。状态基于当前9DA141...E561复音码流及用户冷启动反馈。

| 项目 | 当前状态 | 缺口 |
|---|---|---|
| HDL逐样本实时合成，不播放录音 | 已实现四相位振荡器与实时波形混音 | 准备RTL演示证据 |
| 至少两维交互 | 摇杆X弯音/Y波形，四键选音 | 中心/量程校准、稳定性与交互设计说明 |
| 至少4独立声部 | 已实现四声部，混音试听及冷启动通过 | 四键同时活跃的独立谱峰测量 |
| 单音变调 | 连续弯音、低八度 | 调音/音高准确度实测 |
| ADSR包络调控 | 只有固定起音/保持/松键延时/衰减 | 缺独立Decay阶段和可调Sustain、完整A/D/S/R参数与验证 |
| I2S输出DAC | PCM5102A已发声 | 当前46.875kHz不是标准48kHz；标准采样时钟是改进项，官网该题并未硬性指定48kHz |
| 控制到音频延迟<=10ms | 未实测 | 用示波器同时观察动作信号和DAC模拟输出，测量按键及摇杆路径 |
| 现场多频测试模式及频谱佐证 | 无专门测试模式/实测谱图 | 独立不同频率声部、谱峰、实际采样率和资源/时序说明；勿将波形谐波数当复音数 |
| >=32复音或32加法分量或并行物理模型 | 未实现 | 拓展加分，不是基础4复音门槛 |
| >=3维表情、>=2乐器音色、硬件效果器 | 有弯音/波形和低八度，但无成熟预设或力度控制 | 音色预设、可调包络、第三独立连续表现维度、延迟/合唱等 |
| <=5ms确定性延迟与实时视听反馈 | 未实测，只有心跳/ADC状态灯 | 测量及演奏指引/波形显示等拓展 |
| 脱机LED曲目指引、蓝牙/App | 未实现 | 拓展可选，不要为了数量挤占基础完善时间 |

建议顺序：完整可调ADSR；测试模式及四复音频谱；延迟测量和交互校准；两种可区分的音色；资源评估后做32声部与一种效果器。48kHz改进与抗混叠属于工程质量，勿虚构成官方硬性指标。当前音质受音箱限制尚未量化验收。现有硬件可继续完成多数基础开发，不需因这份清单立即采购。
