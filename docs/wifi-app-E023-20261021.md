# E023 安卓 Wi-Fi 扩展候选

状态：代码与离线验证版本；尚未下载 E023，尚未实物验收。板上已验证的 E021 Flash 保留。

## 对照题目
官方：https://www.gowinsemi.com.cn/university/match2026 。题目提到可搭载蓝牙模块与手机 App 联动，并列举在线曲谱下载、键位自定义、演奏录音回传等扩展。本版用 ESP-01S Wi-Fi 实现附加联动，不宣称已实现蓝牙或保证同等评分；FAQ 的开放扩展口径不能替代实物验收。

实现：手机控制 FPGA 音量、三音色、硬件延时、板载键音区；四触屏键支持多指及四声部重排；FPGA 回传键位、摇杆、参数、运行标志和 32 点输出波形；手机保存变化状态并导出 CSV。

声音计算和 DAC 输出均在 FPGA。触屏键按住期间优先手机，全部松开恢复光键；不宣称两组键同时混音。Wi-Fi 控制没有 ≤5ms 或 ≤10ms 实测保证。32 点波形为约 10Hz 监看，不是无线音频。CSV 是接收状态事件，可能漏掉两个回传帧之间的短动作，不是音频录音。尚未实现在线曲谱下载、离线 LED 曲谱引导、音频录音回传或任意音高键位映射。

## 安装与演示
1. 使用本目录对应 APK（mobile-companion/apk/instrument-companion-debug.apk，版本 0.2-wifi）。若小米拒绝 USB 安装，手动在手机打开 APK 并按系统提示允许安装，不绕过系统限制。
2. 需要配套 E023 FPGA 程序；E021 的单向音量协议不支持本页面状态回传。下载须另按硬件保留措施进行，本次仅构建。
3. 接线保持原表：ESP TX→T12、RX→R11、3V3/GND；PCM USB 供电，PCM 3V3 排针不接。不开新供电并接，不改 EN 接线。历史核心板异常发热根因及 ESP 电源余量尚未测清，软件通过不代表供电已经验证安全。
4. 按现有步骤启用外设：按住 S1+S2，按下并松开摇杆按钮，再松开两键；等待约20秒。重复组合会关闭。异常发热立即全部断电。
5. 手机系统连接热点 FPGA-Instrument，密码 fpga-demo-2026；选择保留无互联网连接。打开伴侣首页“连接 FPGA Wi-Fi”，地址 192.168.4.1，点连接。应用显式使用 Wi-Fi 网络 socket，避免移动网络默认路由影响。
6. 只有出现 FPGA 回传序号且持续变化才算双向连接成功。检查按键/摇杆实际数值和波形，再试音量、音色、延时和四键。先低音量。触屏键可重排四个声部。
7. 开始事件记录，演奏后停止，再导出 CSV。打开文件选择器或离开页面会断开远控；最多5000条，不记录音频。
8. 松开触屏键恢复光键。退出/断网后，FPGA 最迟5秒自动清键、恢复本地音色/音区/延时和满量程远程增益；断开前可先释放触屏键。不要把音箱音量设得过高。

## 协议（TCP 9000）
命令 ASCII：单字符操作码 + 两位十六进制 + LF，每条4字节。V00..FF 音量；T00..02 音色；E00..01 延时；K00..0F 四键位；P00..02 板载键音区；Q00 订阅/续租；L00 释放。手机每500ms续租，FPGA租期5秒。只面向本地演示网，无加密认证，不应对公网暴露；多个客户端以最新合法命令的客户端作为状态回传目标。

回传85字节含 LF：S + 序号4hex + 键位2hex + 标志2hex + X3hex + Y3hex + 音量2hex + 音色1位 + 延时1位 + 音区1位 + 32个8bit波形样本各2hex + LF。标志从bit7到0：armed、optical_valid、controls_valid、test_mode、edit_mode、selected_echo、note_active、remote_active。波形来自最终 PCM 样本高8位偏置128，每4个音频帧抽取一次。快照发送期间冻结，避免同一包数据撕裂。

FPGA 等待 CIPSEND 提示符和 SEND OK 均有超时；手机读取有界且3秒无合法状态即断开。ESP 重启重新配置并清远控。测试/编辑模式抑制手机键进入演奏路径。
