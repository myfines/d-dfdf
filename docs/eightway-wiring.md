# 亚博八路模块四线接法（2026-10-12）

依据用户专用说明 E:/keil/小车源码/0.8路巡线模块的使用方法/8路巡线模块的使用方法.pdf。图示型号YB-MX04-1.0；按实物丝印核对，不按线色判断。

采用独立I2C接口，保留已有ADS1015接线：

| 模块丝印 | 连接 |
|---|---|
| 5V | 独立稳压5V/USB取电板5V，或已确认的MSPM0板5V输出；不得接12V、Dock3V3或GPIO |
| GND | 5V电源GND和Dock GND共地 |
| SCL | Dock PMOD0的T9（新接口） |
| SDA | Dock PMOD0的P9（新接口） |

T9/P9在现工程未使用；已有P6/R8/P8用于PCM，T6/T7用于ADS，T8用于摇杆SW，保持不动。已核对SOM原理图与原Pnr：T9/P9为bank3、3.3V，连接LVDS_IOR38_P/N，非核心板实际Flash网络（Flash使用P10/R10/M10/L10等）。新固件要按I2C开漏配置T9/P9，当前7799未实现此驱动。

图示正面（KEY/RESET在左、两个白座在右）：右侧白色座为I2C，四位丝印从左到右GND/SDA/SCL/5V；左座是RX/TX/GND/5V串口座，不选它。也可直接用底部排针的5V/GND/SCL/SDA四脚，其他KEY/RESET/X1-X8/TX/RX均不接，背面3.3V调试焊盘不作为本方案供电入口。PH排线可能反向，必须逐线按丝印核对。

厂家对应款公开回复通信为3.3V逻辑，供电为5V：https://category.yahboom.net/products/8-lp 。不把未核对型号的其他模块都视为同一电平。

先独立校准模块：FPGA保持断电，SCL/SDA先悬空，只给模块5V/GND。每次上电等至少20秒；首次/更改高度时长按KEY进入校准，在实际使用高度对黑面静止3秒、短按KEY取样；对白面静止3秒、短按KEY取样。成功后红灯熄灭，值断电保存。失败慢闪需重做。它是反射式检测，手指与小挡片的极性/距离要按实际使用方式校准。

I2C7位地址0x12，寄存器0x30返回8状态位，x1 bit7/x8 bit0。专用PDF例子B01111111写成0x8F是笔误，正确为0x7F（127）；不要照错例编码。

这里只完成接线方案，未操作板卡或烧录。热故障根因仍未验证；新驱动和低活动修正版未部署，不应认为接好即可使用八键或进行长期运行测试。

## 用户实际ST-Link供电接法

照片红壳Zave/泽而V2标注：9/10=5.0V，5/6=GND，7/8=3.3V。选9供模块5V；5供模块GND；6接Dock真实GND形成三方共地。SCL仍T9、SDA仍P9。9/10和5/6各组不需两脚都接模块；借第二个GND可省去额外分线。按实物编号确认插针位置，外壳图与端面可能镜像；照片只确认标注，非电压/输出电流实测。模块5V与Dock3.3V不并接。当前接口固件未部署。
