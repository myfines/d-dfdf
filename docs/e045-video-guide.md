# 最后拍摄演示时的顺序

先完成最后修复、最终版本固化与用户冷启动反馈，再开始成片。镜头中不出现学校名称/校徽等身份信息；以当届正式提交要求核对时长/格式，不把本清单建议当官方规定。

1. **全景与身份，约15秒：**FPGA板、传感器、K230、DAC、音箱和手机同框，说明高云FPGA完成音频/视听，K230仅做动作识别。展示最终版本与报告hash。
2. **至少2维交互，约40秒：**先光键单音、松键、和弦；保持音符时捏合改变音量，接着摇杆弯音、手势高度改变亮度，再同时控制。手机已连接状态也重做关键动作。
3. **4复音/4音色/ADSR，约45秒：**保持四音，逐个释放，其他音持续；同一个短乐句切电钢琴/风琴/弦乐/Bass。Bass用低音区，关闭效果先听干声，再演示起音与尾音。
4. **效果和硬件视听，约35秒：**固定音符/节奏，逐次开合唱、延迟、混响，留足松键后的尾音；近摄OLED波形、频谱、XY和LED。手机画面不能替代FPGA OLED证据。
5. **32音测试，约25秒：**降低音箱音量，启用测试模式，配对应录音分析图和32状态说明，说明独立voice与设计采样率。未做LRCK实测时只报设计值，不声称评分已认证。
6. **App与脱机，约60秒：**原版主界面→设置→直连扩展；曲谱下载回读→播放→断开手机→S3/LED指引；重新连接演示位置0→12并弹键核对，恢复0→0；短录音128块→保存WAV→播放器回放。
7. **延迟与冷启动证据，按实际加入：**若取得同步仪器波形，画面标出两通道、起点/终点、min/max与原始文件索引；没有测量不要配伪造波形或写≤5ms通过。用户完成冷启动后保留连续上电/启用/发声镜头。

每段使用最终同一版本，拍摄前关闭压力测试、锁存和旧曲谱；音箱增益保持固定。音色对比不要逐段自动归一化，也不要后期替换现场声音。具体开拍时代理按此顺序逐步指导并根据实际结果调整。
