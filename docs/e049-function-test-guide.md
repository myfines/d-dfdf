# E049＋App0.12 完整功能点检查指南

目的：只查对应功能是否存在、能否操作和产生对应现象。每项记录“有／异常／未测”，不测延迟数值、不做音质评分，不把本清单当成官方性能验收。建议按顺序测试，约30–45分钟；异常项记编号和现象即可。

当前板卡Flash与正式运行版本E049，已读回E049/6020。手机须使用 `mobile-companion/apk/instrument-companion-0.12-e047-expression.apk`，安装包名含e047仍兼容E049。若设置里没有颤音、ADSR、三效果器等入口，先核对是否安装了旧APK。

## 0. 准备与回到基准状态

沿用现有接线，不在测试时改线。先PCM供电，再Dock/K230；音箱低音量起步。若现在已正常上电，不必为这份功能检查反复冷启动。电脑保持原网络，只有手机接ESP热点。

启用：按住S1＋S2，按下并松开摇杆，再松开S1/S2；只做一次。等约20秒初始化。反复组合会关闭外设。

先保持手机App断开，完全松开光键与手势。若仍有持续演奏，依次确认S3短按曲谱停止、S3长按约1秒锁存关闭、S0长按约1秒32声部模式关闭。长按和短按作用不同；S0–S3按下本身还会触发对应高音，松开后的模式动作才是本项要观察的行为。

基准：风琴、无效果、音区1、无锁存、无曲谱、无32声部测试。后续连接App后音量设160、颤音0，并“恢复四音色原厂包络”。若已有未释放声部，先松开再按。

## 1. 手机断开：本地功能

| 编号 | 功能与操作 | 看什么 | 恢复／注意 |
|---|---|---|---|
| L01 | 逐个触发八路光键，每路按住再松开 | 八路分别能发音、松开能结束，OLED指引页下半格对应实际光键 | 先确认实际通道方向；不要预设模块放置方向等于左→右编号 |
| L02 | 同时保持四个光键，再逐个松开 | 有和弦，各键释放不应让剩余键一起消失 | 关闭锁存、曲谱与测试模式；音色正常释放尾音允许存在 |
| L03 | 单击摇杆，循环四种音色；每次重新按同一光键 | 电钢琴、风琴、弦乐、Bass均有声，音色切换可听出差异 | 四音色不是四种颤音；切换后重新触发，旧声部可能保留原音色 |
| L04 | S1短按松开，循环四音区；每区按同一位置 | 同一位置音高随音区变化，四区可循环 | 最后回音区1；这是八键分区，不要求每次恰好升八度 |
| L05 | 保持一个风琴音，摇杆左右移动后回中 | 音高连续变化并回到原音附近 | 不把音量变化当作弯音 |
| L06 | 摇杆上下分别放两个位置，每个位置重新按同一键 | 新触发音符力度／响度不同 | 力度在触发时取样，不要仅持续按音后移动判断失效 |
| L07 | 保持风琴音，对摄像头做张开／捏合 | 响度随捏合变化 | 手势本身不触发音符；要先有持续音 |
| L08 | 保持音符并尽量固定捏合，改变手部高度 | 亮暗／高频成分变化 | 判断的是音色明亮度，不是必须改变音高 |
| L09 | 发声时让手离开识别范围，再重新进入 | 不应卡在丢手前的极低音量或旧手势状态；重入后可继续控制 | 记录“丢手后无声／重新识别无恢复”等具体情况 |
| L10 | S0短按循环：关→合唱→合唱＋延迟→全开→关 | 厚度、重复回声、空间尾音等对应变化 | 每次弹短音后听松键尾音，最后回关闭 |
| L11 | S3长按约1秒，按光键后松开，再按同一键；再长按关闭 | 锁存开启时松手可保持，再按切掉；关闭后恢复按住响松开释放 | 此项测试完必须关闭，避免影响四音和松键测试 |
| L12 | 音箱先调低，S0长按约1秒启动，再长按停止 | 多音测试能启动、有声、能停止 | 摇杆长按也可切测试模式，平时切音色请短按 |
| L13 | S3短按启动内置曲目，再短按停止 | 未连接手机也能播放内置示例，OLED/LED随曲目变化 | 这一步先于下载自定义曲谱；停止后再做后续项目 |

## 2. 手机连接与基础控制

手机连接 `FPGA-Instrument`，密码 `fpga-demo-2026`；无互联网提示选择保持。App地址 `192.168.4.1`，端口 `9000`，点击连接。设置音量160、音区1、风琴、颤音0，扩展中所有效果先取消并应用，恢复原厂包络。

手机连接时，音色／音区／效果／显示等远控目标会接管对应参数；这些项目优先在App操作。不要拿此时板载S1或摇杆切音色未生效来代替测试App是否可控。

| 编号 | 操作 | 看什么 |
|---|---|---|
| P01 | 连接后观察状态、手势数据和波形 | 能收到设备更新，操作时回传有对应变化，不只停在“连接中” |
| P02 | 手机八键逐个按放，再四指同时按，逐个放开 | 能单音／多音演奏、松开释放；若手机触控限制四指，先用四光键测L02，本项记设备限制 |
| P03 | 同一音符下调音量160→80→160，再静音、恢复160 | 音量有变化，静音有效，恢复后可重新发声 |
| P04 | App选四音色、四音区，每次重新按音 | 四音色均响，四音区确实改变同位置音高 |
| P05 | 手机按住一个音，再分别做捏合、高度变化、摇杆左右；最后同时操作两种控制 | 手机连接后本地表情仍可用，没有“连接后捏合失效”的问题 |
| P06 | 手机松键，App断开，等最多5秒；用光键演奏，再重连 | 手机音不应一直挂住；本地可演奏，重连可再控制 |
| P07 | 非零颤音和App32音测试关闭前做一次断开重连 | 新连接不应自动复活旧颤音／旧App32音测试 | 

## 3. App扩展：表情、包络、效果、测试模式

入口：原版自绘主界面 → 设置 → 直连扩展。对话框较长，可上下滑动；应用参数后关闭扩展和设置，返回键盘重新按音。每次只改一项。

| 编号 | 操作 | 对应现象／恢复 |
|---|---|---|
| X01 | 颤音输入0，试听；再输入160应用，试听；最后回0 | 非零时音高周期性摆动，回0后消失。当前颤音没有参数回读，发送提示本身不算试听成功 |
| X02 | 按下表逐组设置ADSR，等“FPGA已回读”后重新按音 | 不同起音／衰减／保持／释放可控制；完成后点“恢复四音色原厂包络”并等回读 |
| X03 | 三效果先全关并应用；分别只开合唱、只开延迟、只开混响，最后三者同时开 | 合唱听厚度／轻微摆动；延迟听重复声；混响听松键空间尾音；每组都与全关比较，结束全关 |
| X04 | 音箱调低，点击“启动32声部测试”，再查看OLED系统状态页，最后点停止 | 模式能启动、有多音输出、声部显示可到32，能停止。本项只查功能，不能凭听感或数字证明32个可闻声部 |

ADSR输入顺序均为 **A／D／S／R**。A/D/R为0..15索引，越大越慢；S为0..255电平。测试前关闭效果器和颤音，用同一键、同一音量。

| 对比目的 | 第一组 | 第二组 | 听什么 |
|---|---|---|---|
| 起音A | 0／0／180／0 | 15／0／180／0 | 第二组按住约2秒，声音起得更慢 |
| 衰减D | 0／0／40／0 | 0／15／40／0 | 第二组从较响逐渐降到较弱保持声，第一组更快落下 |
| 保持S | 0／0／40／0 | 0／0／220／0 | 按住后的持续音第二组更响 |
| 释放R | 0／0／180／0 | 0／0／180／15 | 第二组松键后消退更慢；等约2秒再比较 |

## 4. OLED五个页面与LED

手机未连接时S2短按轮换；手机连接时在扩展中选择页面再点击“切换OLED页面”。测试页面时保持一个音或弹几个不同音，不能只看静音画面。

| 编号 | 页面 | 功能存在的现象 |
|---|---|---|
| V01 | 波形 | 发声时有随声音变化的波形 |
| V02 | 16带频谱 | 发声时出现频带条，不同音高或亮度下分布变化；不要求16根总是都亮 |
| V03 | 立体声李萨如 | 有随左右声道变化的XY图；可开合唱观察。干声左右相同时一条斜线正常，不要求总是圆 |
| V04 | 曲目指引 | 八格1..8可见；上半格为目标键，下半格为实际光键，目标音符和BANK提示可见。详测见下一节 |
| V05 | 系统状态 | 音色、效果、声部数等字段可更新，可看到`32 VOICE HDL TDM` |
| V06 | 板载LED | 曲目启动后四灯有分组提示／节拍变化，停止后回自由演奏显示。纸壳遮住时记“不可见／未测”，不要记不存在，也不要用OLED替代这一格 |

巡线模块自身八颗指示灯只查“触发对应探头时有没有状态变化”。它们不是可按曲谱主动控制的八颗提示灯，此功能不列为已实现。

## 5. 曲谱下载、映射与精确指引

先选音区1、关闭锁存和32音测试。推荐慢速测试谱如下，四个事件依次是C3、C4、休止、G5，各1秒：

```text
0:100,12:100,-:100,31:100
```

| 编号 | 操作 | 看什么／恢复 |
|---|---|---|
| Q01 | 输入慢速谱，点“下发曲谱到FPGA并回读确认”，再播放／停止 | 回读曲谱就绪及事件数成功，听到按序音符和空白休止，播放／停止可控制 |
| Q02 | 播放时看指引：当前音区1遇C4，应提示BANK2；切音区2后看C4 | 音区1不应把C4冒充为当前第5键；音区2应上半格提示第5键，实际触发该光键时下半格亮 |
| Q03 | 看休止事件 | 显示REST，清除上半格目标；没有手动演奏、效果尾音或锁存时曲谱该段不发声 |
| Q04 | 下发成功后停止播放、断开App，等最多5秒，用S3启动／停止 | 无手机连接仍能播放下载的谱并驱动指引；下载谱断电丢失属于已知设计，不是下载失败 |
| Q05 | 重新连接并停止曲目，松开所有键；映射位置0→12，等回读后在音区1按第1键 | 第1键由C3变成C4；手机第1键与对应光键都应遵循映射 |
| Q06 | 保持0→12映射，播放慢速谱看C4目标 | 当前音区1应提示第1键，不再要求音区2；完成后停止曲目、恢复0→0、回读并试按 |

“UNMAPPED”只在所有32个映射位置都没有目标音时出现。若想测试：将位置0→12后播放目标0，其余位置保持默认，原C3已无映射，应显示UNMAPPED。完成后恢复0→0。此项记Q07。

播放按钮文字是“播放／停止曲谱”，重开对话框后本地切换状态可能重新开始计数；以实际声音和OLED SONG状态判断，必要时再点一次，避免误把本地按钮状态当设备状态。

## 6. 在线获取曲谱

Q08：手机先使用有互联网的网络，打开扩展，将以下**最终文本网址**填入在线曲谱地址，点击“从互联网获取曲谱并保存到手机”。本轮已确认网址HTTP200、内容是合法曲谱：

```text
https://raw.githubusercontent.com/myfines/d-dfdf/e031-web-control/docs/demo-score.txt
```

应该填入下载后的音符文本，并提示已校验／保存。随后切回ESP热点，重连App，确认缓存仍在，再点击“下发曲谱到FPGA并回读确认”并播放。完整走完才记“在线获取＋下发功能有”。网址若被当前网络屏蔽，记网络未通，不擅自改用网页或音频地址。

支持UTF-8文本，不是网页、MIDI或MP3；最多64事件、8192字节。没有曲库搜索功能。ESP热点无互联网时不能要求同时从公网下载，先下载再切热点是正常流程。

## 7. 录音与导出

R01：恢复原厂ADSR、关闭曲谱/锁存/32音和效果，手机已连接。扩展里点“录制设备PCM并导出WAV”；对话框返回主键盘后立刻弹音。等待128块接收完成，选择手机保存位置。用手机播放器打开WAV，确认文件可播放且有刚才的声音。

这是约0.7秒、8bit、单声道的短录音；不是连续长录音，不能以“录不了一分钟”判功能缺失。若来不及弹进短窗口，可先在手机主界面音区确认好，再使用一个持续的光键音进行录制，录完立即松开。打开系统保存／播放器后App可能断连，回到App须重连再测后续功能。

## 8. 简单恢复检查与结束状态

| 编号 | 操作 | 看什么 |
|---|---|---|
| B01 | 录音/应用参数时退出连接或切后台，再回来重新连接 | 允许报告取消／断开；不能一直卡死，重连后仍可弹音 |
| B02 | 映射输入32或ADSR输入16作为A值，点击应用 | 有范围错误提示，App不崩溃；随后改回合法值 |
| B03 | 在线曲谱填明显不合规内容的网页地址或无效地址 | 报下载／格式错误，不能误报下发成功；随后清理地址再正常操作 |

结束恢复：曲谱停止、锁存关闭、板载与App32声部测试都关闭、颤音0、三效果全关、原厂ADSR、映射0→0、音区1、音量160。不要通过反复按启用组合来恢复这些参数。
