# 八路巡线模块作为光电琴键：资料评估

2026-10-12，读取用户PDF：E:/keil/小车源码/0.8路巡线模块的使用方法/8路巡线模块的使用方法.pdf（三页），视觉核对图片为YAHBOOM YB-MUX04-1.0八路板。实物是否同型号仍需核对。厂家同版说明：https://www.yahboom.net/public/upload/upload-html/1731564712/8-channel%20line%20tracking%20module%20usage.html 。

可作为八个反射式光电触发点，不是机械键或电容触摸键。向上安装探头，用手指或白色小拨片改变反射量形成触发，需实际检查距离、相邻通道串扰、环境光及多通道同时检测。不能保证任意距离挥手可靠。更稳妥的机构可让每个小翻板仅靠近对应探头。

支持三种接口：X1–X8直读数字IO；串口可读数字/模拟；I2C读数字。优先评估I2C，文档地址0x12、状态寄存器0x30，可与ADS1015的0x48考虑共用总线，节省八根GPIO线，但主机需统一事务调度，不能让两个独立驱动状态机同时发交易；先核对输出电平、上拉电源和地址约定。板上5V供电标识不能证明信号脚是3.3V，资料无明确电气规格，当前不提供直连FPGA方案。

文档I2C位序示例有错误：B01111111应该0x7F/127，并非写出的0x8F；本地PDF第二例B01011111与0xAF/175不一致，厂家网页第二例又写B10101111。必须逐探头确认极性/位序，不直接按这些示例定义琴键。

校准按文档：每次上电等待至少20秒；进入KEY校准，在实际使用高度采集黑、白参考，成功后保存，改变环境/高度需重新校准。用于手指时仍须验证两种目标反射差异适合该模块，不能把黑白线校准直接当作手指识别已成功。

软件后续可将8位状态转成独立NoteOn/NoteOff，做迟滞/消抖与多键判断。八个输入不自动等于八复音；需评估声部架构与资源。当前FPGA仍有快速热故障暂停，只能做方案/离线开发，不能立即接模块通电。未测模块电平、未接线、未访问FPGA或烧录。
