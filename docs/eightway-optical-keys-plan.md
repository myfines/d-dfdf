# 八路巡线模块作为电子乐器输入的可行性

2026-10-12，仅资料核实与方案，未接线/上电/烧录。用户反馈现有全部功能包括包络短时测试正常；这不是热故障根因或热安全验收。

本地依据：E:/keil/小车源码/2.小车案例/6.MSPM0-轮式小车底盘V2/八路巡线模块/接线.txt、基于八路巡线模块的小车巡线.pdf、BSP/Eight_Tracking/app_irtracking.h/.c。接线VCC5V、GND、SDA、SCL；IR_I2C_ADDR=0x12；写寄存器指针后读取0x30一字节，x1对应bit7、x8对应bit0。参考描述白底1/黑线0，实际触发极性须校准，不把手遮住必为低当硬性事实。

厂家对应产品：https://category.yahboom.net/products/8-lp 。2026-08-30厂家答复UART/I2C逻辑3.3V，兼容3.3V MCU；供电5V与通信逻辑电压不同。对应协议：https://www.yahboom.net/public/upload/upload-html/1731564712/8-channel%20line%20tracking%20module%20usage.html 。本地与官方地址/状态寄存器匹配。仍须实物照片确认同一型号/接插件线序，不照PH排线颜色/正反方向猜。

拟用作8个反射式光电触发键：稳定白/黑反射面或机械小挡片，输入极性可选，加入同步/滤波、NoteOn/NoteOff和断连全松。不是对射断光的激光竖琴，探测距离/材料/相邻串扰及手指是否稳定触发须实测。数字状态可表示多个键同时触发，不能直接称为力度/压力传感。

只需4线（5V/GND/SCL/SDA），不需要8根GPIO，不需要电机或小车主控。可采用独立I2C接口，或在ADS1015总线上增加单主机调度（0x12与0x48不冲突）；不能简单把两个现有独立I2C主状态机并接同一总线。具体FPGA脚位待型号/接插件确认后核对空余3.3V Bank。模块5V供电不得接FPGA3.3V电源或GPIO。

现程序只支持4个演奏键，8路传感器不等于8复音；需修改演奏输入/声部分配。优先扩展为8音符输入和4/8声部调度，复用算术降低资源与空闲活动，不直接翻倍复制DSP引擎。保持现有ADSR/摇杆功能，原S键可转为音色、八度和参数控制。未部署，发热事件仍保留待查状态。
