## 需收紧的报告结论
1. 延迟：专用latency_selftime的引脚边沿到首样本只是数字子路径；需源码与事件定义，确认消抖/真实光键I2C路径/包络/I2S通道时序。PCM模拟群延迟未实测，不能把估算<1ms升级为完整成品≤10ms验收，余量10–30倍也非本轮已证结论。
2. 时钟：250ms UART帧经主机时间观察不能独立精确标定27MHz；存在缓冲、调度和时间基准误差，BCK/LRCK读数也需原始测量来源。
3. 摇杆：源码确认X固定中心825、±25死区；静止845本身位于死区内，不应必然弯音，需超界原始样本与录音对应证据。整体约+0.53%频偏与超界+44计数在量级上相符但不是唯一因果证明。
4. 音色：源码确有按Y混锯齿的亮度设计，非所有混入都是缺陷；Y约330按mix公式约20%有依据，但不能直接把它定义为相对825中心的偏差。三预设需各自检查混音路径；改为中心相对映射前应明确目标语义与双向范围，不能简单X/Y都减零点便认为修复完成。
5. 32测试：可与既有10月15日32频点证据互补；需原录音/频谱脚本、最终版本对应与分频定义，不能凭图片引用全额验收32完整可调声部。
6. 温升、电流、长期稳定性、冷启动重复性仍明确未测，不能由“核心链路全通过”推导稳定性已解决。

建议下一步先补齐脚本/原始遥测/录音/延迟源码及对应构建配置，再设计显式摇杆校准（稳定采样、范围/死区、参数限幅、失效保护），用仿真和SRAM验证，不直接固化Flash。
